## 1. 语义

记：预测剩余手牌 \(H\)（已打出后）、该家**最近一张弃牌** \(d\)（`discards[-1]`）。

| 相位 | 关联含义 | 打分方向 |
|------|----------|----------|
| **前** early（弃牌数 ≤2） | \(d\) 与 \(H\) 的**搭子/面子组合**相关度 | 相关度 **高 → 假设差**（早期应打散张，不该拆有用组合） |
| **中** mid（3–6） | 组合相关 + 开始考虑「打 \(d\) 是否损害向听」 | 相关/损害 **高 → 降权** |
| **后** late（≥7） | \(d\) 与 **听牌/进张** 相关度（向听差分、听口） | 相关度 **高 → 降权**（应打废张） |

**定缺**：若 \(d\) 为定缺色，或评估时只看非定缺子牌——**本规则返回关联度 0**（不参与惩罚）。

---

## 2. 公式草案（实现常量可调）

### 2.1 组合关联 `combo_assoc(d, H) ∈ [0,1]`

- 同 `tile_id` 在 \(H\) 中每张 +0.45（封顶 0.9）  
- 同色 \(|rank-r|=1\) 每张 +0.28  
- 同色 \(|rank-r|=2\) 每张 +0.12  
- 结果 `min(1, sum)`  

### 2.2 听牌关联 `tenpai_assoc(d, H) ∈ [0,1]`

1. 若 \(H\) 向听 = 0 且 \(d\) 的牌面 ∈ `ukeire(H)` → **1.0**（听口相关极高，不合理）  
2. 构造打出前 14 张 \(H\cup\{d\}\)，枚举少量子集比较：打 \(d\) 后的向听 `sh_d` vs 打其它张后的最优 `sh_best`  
   - 若 `sh_d > sh_best` → 关联/损害 `min(1, 0.45 + 0.25*(sh_d-sh_best))`  
3. 再混入 `0.4 * combo_assoc`（中期更高混合）  

### 2.3 权重

```
early:  w *= max(0.15, 1 - 0.60 * combo_assoc)
mid:    w *= max(0.12, 1 - 0.55 * tenpai_assoc)   # tenpai 含组合分量
late:   w *= max(0.10, 1 - 0.70 * tenpai_assoc)
```
