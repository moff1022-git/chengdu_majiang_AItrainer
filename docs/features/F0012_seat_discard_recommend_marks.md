# F0012 — 座位窗推荐出牌标记

| 字段 | 值 |
|------|-----|
| **编号** | F0012 |
| **状态** | **`Done`**（用户直接要求并实现） |
| **依赖** | `rank_discards` / F0011（与 human_proxy 分析一致） |
| **入口** | `players/seat_window.py`；逻辑 `players/analysis/discard_recommend.py` |

## 规则

1. 推荐算法与既有 **`analyze_for_seat` → discard_ranks** 一致（规则 AI / F0011 由 proxy 传入 hints）。  
2. **若存在打出后向听=0 的候选**：推荐 **全部** 可听牌；序号按原 score 序 1…n。  
3. **否则**：最多推荐 **3** 张（原 rank 前 3）。  
4. 推荐张在牌面 **右下角** 标数字序号。  
5. **焦点**（单击选中）在某推荐牌上且该牌打出后听牌：在 **手牌区上方独立「可听进张」条** 完整展示全部可胡张（禁止按单张手牌宽度裁切）。  
   - 牌面尺寸：约 **32–40 px** 宽（随窗宽略缩放，**不得**压到 ≤22px 的迷你格）。  
   - 顺序 **万→筒→条**，同花色 **从小到大**。  
   - 每张进张 **剩余张数标在该牌面上方**（不遮挡牌面）。  
   - 无焦点/非听推荐时条内为空或提示文案，不占用手牌单元格内部空间。  
6. play 模式、出牌阶段；可开关（默认开）。  
7. 换三张选中按 **手牌位置索引**（相同 tile_id 可只选一张）。  
8. 防闪烁：手牌区尽量 in-place 更新；进张条独立刷新（缓存键避免无变化时重建）；手牌指纹不含对手分数/手牌数；选中仅边框/底色不高亮放大。  

## Out of Scope

- 主桌 pygame HUD 同步  
- 观战座无 hints 时重算（无 engine 手牌）
