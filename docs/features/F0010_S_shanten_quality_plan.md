## 1. 问题诊断（为何 L2 表对了、MAE 仍高）

### 1.1 现象（fixed set 锚点）

| 来源 | overall best | Top1 | late best | **Top1 向听 MAE** |
|------|--------------|------|-----------|-------------------|
| set50（blend 0.76/0.24，`100802`） | 0.511 | 0.435 | 0.521 | **~2.05** |
| set20 L3 后 | ~0.50 | ~0.42–0.43 | ~0.50–0.51 | **~2.14–2.17** |
| L2 前 | ~0.50 | ~0.42 | ~0.50 | ~2.14 |

对照：L2 把 **target(n_disc)** 校准到真值均值后，**target 相对 true 的误差**可降，但 **pred_top1_shanten 相对 true_shanten 的 MAE 几乎不降**。

### 1.2 根因分层

```
真手牌 sh* ────────── MAE ≈ 2.1 ──────────► 展示/排序用的 pred sĥ
        ▲                                    ▲
        │ 候选池里就没有接近 sh* 的手      │ 即使有，排序仍推「假近听」
        │ （生成/连续/结构错）               │ （奖励听近、结构代理过强）
```

| 层 | 问题 | 已做且不够 | 本计划方向 |
|----|------|------------|------------|
| **A. 目标标定** | 旧公式系统性偏低 | L2 表 ✅ | 维持；仅诊断用 |
| **B. 候选生成** | MC/beam 采样的手 **结构不像真牌**（过「听」、花色错、搭子假） | 配额/斩色/DH 部分缓解 | **S1 生成约束 + 再生** |
| **C. 向听用于排序** | 对 **差候选** 算真 sh 会给 **错误高分**（假听近） | L3 blend 0.30 已回退 | **S2 可信度门控 + J4** |
| **D. 展示/诊断** | 只有 MAE 均值，不知 late 是否更糟、best 场景 sh 是否更好 | raw_stats 有均值 | **S0 诊断切片** |

**一句话**：不能再「更信向听分」；要先让 **存活假设的 sh 分布** 贴近真值，再让排序在 **可信区间** 内用 sh。

### 1.3 与 F0010-ML 的边界

| 计划 | 做了什么 | 不做 / 交给 S |
|------|----------|----------------|
| M1–M2 | mid 止血、斩色 | — |
| L1 | 连续 C1 重生 | 重生时结构/向听门禁 → S |
| L2 | target 表、late 结构×、G4/G5 | 未解决假近听 |
| L3 | T/MMR/blend/合规 | **Out of Scope for S**（不再调） |
| **S** | 候选质量 + 向听可信使用 + 诊断 | 学习排序 J5；完整 J2 waits×M08（可后置） |

## 2. 目标与成功标准

### 2.1 主指标（fixed set，相对 S 前 set50 锚点）

| 指标 | 锚点（约） | **S 验收（≥）** | 挑战 | 说明 |
|------|------------|-----------------|------|------|
| **Top1 向听 MAE** | 2.05 | **≤ 1.85**（降 ≥0.20） | ≤ 1.70 | **主门禁** |
| late Top1 MAE | ~2.0+（待 S0 切片） | 降 ≥0.20 | 降 ≥0.30 | 相位主战场 |
| overall best F1 | 0.511 | **≥ 0.511 − 0.01** | ≥ 0.520 | 不伤 best |
| overall Top1 F1 | 0.435 | **≥ 0.435**（不降） | ≥ 0.45 | 期望随 MAE 降而升 |
| late best F1 | 0.521 | **≥ 0.521 − 0.01** | ≥ 0.535 | |
| mid best F1 | 0.489 | **≥ 0.489 − 0.01** | ≥ 0.495 | 门禁：不伤 mid |
| early best | ~0.47 | 降幅 ≤ 0.015 | — | |
| deep best | ~0.59 | 降幅 ≤ 0.025 | — | |

### 2.2 诊断副指标（S0 起必报）

| 指标 | 含义 |
|------|------|
| MAE by phase（early/mid/late/deep） | 是否 mid 仍被拖累 |
| MAE of **best-F1 hyp** 的 sh vs true | 候选里是否已有「向听也对」的假设 |
| mean (pred_top1_sh − true_sh) 有符号偏差 | 系统偏「假近听」还是「假远听」 |
| frac(pred_sh ≤ true_sh − 2) | **假近听**比例 |
| late：Top1 与 best 的 sh 差 | 排序是否把更好 sh 排到后面 |

### 2.3 回滚条件

| 条件 | 动作 |
|------|------|
| mid best 降 > 0.01 | 回滚该批 |
| early 降 > 0.015 或 deep 降 > 0.025 | 回滚 |
| MAE 未降但 F1 崩 | 回滚 S2 向听门控 |
| set20 吞吐 > 1.5× 基线墙钟 | 收缩 S1 再生次数 / 限制 late only |

## 3. 分批计划

### 批次 S0 — 诊断与日志（必先做，几乎不改策略）

**意图**：用现有 jsonl 证明「假近听」与「best 场景 sh 更好但未排第一」是否成立。

| 步 | 内容 | 产出 |
|----|------|------|
| S0.1 | `analyze_predict_logs` / 脚本：按相位聚合 MAE、有符号误差、假近听率 | `docs/status/F0010_S_shanten_diagnostics.md` 或 ANALYSIS 新节 |
| S0.2 | 每 opponent 样本：记录 `true_shanten`、`pred_top1_shanten`、`best_f1_hyp_shanten`（若日志已有 hypotheses[].shanten_est + f1） | 扩展 raw_stats |
| S0.3 | 固定结论写入本计划 §1（或附录）后，再开 S1 | 避免盲改 |

**S0 验收**：一页诊断表；**不要求** F1 变化。  
**实现量**：分析脚本 + 可选 analyze 增强；**可不改** `hand_predict` 采样。

---

### 批次 S1 — 候选池：抑制「假近听」生成（最高优先实现批）

**意图**：在 **采样 / 精炼 / 连续重生** 阶段，减少「结构破碎却 sh 很低」或「sh 低但与弃牌时间线冲突」的假设进入 Top 池。

| 步 | 规则 ID | 调整 | 类型 | 风险 |
|----|---------|------|------|------|
| S1.1 | **新 S-GEN1** | late：采样后若 `sh < target(n_disc) − Δ`（建议 Δ=2）且 **主色 conc 低 / 斩色色持有超 cap** → 丢弃或强制重采样 | H/S | 中 |
| S1.2 | **新 S-GEN2** | late refine/swap：接受交换的条件增加「sh 不升」或「\|sh−target\| 不恶化」 | S | 中 |
| S1.3 | **L1 重生加固** | C1 失败受限重生：补摸 prefer 后若 sh 相对 target 过优（假近）且 DH/斩色差 → 再抽一次（上限 2） | P | 中·CPU |
| S1.4 | **结构下限** | late：`_structure_score` 低于阈值的手，采样权重 ×0.3（与 G1 加分对称的「过烂结构」罚） | S | 低 |

**原则**：门控用 **target 表（L2）+ 可验证弃牌事实（斩色/DH）**，避免只信 engine sh。

**S1 验收**：set20 上 MAE 降 ≥0.10 或假近听率降 ≥20% 相对；mid 不伤。

---

### 批次 S2 — 向听用于排序：可信门控 + J4 后继（谨慎）

**意图**：仅在假设「时间线合理」时放大 sh 贡献；落实规格 **J4**（出牌后向听不应无故变差——在 **连续场景** 上可检验）。

| 步 | 规则 ID | 调整 | 类型 | 风险 |
|----|---------|------|------|------|
| S2.1 | **J4 软→半硬** | 连续路径：出牌家 C1 演化后，若 `sh_after > sh_before + 1`（无副露变化）→ 权重 ×0.4 或丢弃该连续场景 | S/H | 中 |
| S2.2 | **S-TRUST** | late 终评：仅当 `\|sh − target\| ≤ τ`（τ=1.5 或 2）时，sh 项全权；否则 sh 贡献衰减（如 ×0.35） | S | 中 |
| S2.3 | **反假近听** | pred sh ≤ target−2 时 **额外惩罚**（与 G5 听牌 bonus 对冲：bonus 仅当 timeline 合规） | S | 中 |
| S2.4 | **blend 保持** | **不**提高 `LATE_BLEND_SHANTEN`（维持 0.24）；S2 改的是 sh 项形状，不是权重再加压 | — | — |

**S2 验收**：MAE 再降，使累计相对 S 前 ≥0.20；Top1 F1 不降；rank1=best 不崩。

---

### 批次 S3 — DH / 听口质量（可选，接 F0011）

**意图**：中后路径 tenpai 关联用真向听，服务预测与防炮。

| 步 | 内容 | 风险 |
|----|------|------|
| S3.1 | mid：**抽样**（如前 20% 候选）开 `full_tenpai` DH，其余仍组合代理 | CPU |
| S3.2 | late Top-K 终评：对 top 场景算 ukeire 与 true 听牌重叠率（诊断）；可选软分 | 中 |
| S3.3 | **不做**完整 J2×M08 融合（另立 F001x） | — |

**S3 验收**：DH 相关 late/mid F1 不降；可选 ukeire hit 提升。可与 F0011 放炮评测并行。

### 批次 X — 明确不做

| 项 | 原因 |
|----|------|
| 再调 L3 T / MMR / blend 主系数 | 已证边际耗尽 |

| 改 early 均匀主路径 | 门禁保护 |
| 完整 waits 网络 / 端到端 RL | 超范围 |
