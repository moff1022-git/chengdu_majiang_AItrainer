# F0054 Nonhuman联合门禁与弃牌密集特征筛选

- 状态：Approved for read-only screening
- 日期：2026-08-04
- 前置：F0050–F0053关闭

## 目标

停止稀疏杠分叉调参，建立跨数据集联合评价，并只读采集全部s0弃牌候选，检验多步有效进张、牌型价值与公开危险度是否能形成稳定密集信号。本阶段不改变业务决策。

## 联合评价

正式候选必须同时满足：

1. 主集、seed-a、seed-b配对总分差均大于0；
2. 合并配对bootstrap 95% CI下界大于0；
3. 胡牌数、自摸数不得在任一数据集出现预注册的实质退化（分别不低于基线2‰和1‰以上）；
4. 花猪率不得上升；
5. 负向单局分差P95与最差1%均不得恶化；
6. 所有输入来自PlayerView/PublicBelief，不使用未来牌墙或对手暗手。

## 只读采集

三个数据集各取固定前1000局，按旧`.50`原策略重放并采集每个s0 discard候选：

- 当前/弃后向听；
- 当前实现的ukeire（用于确认稀疏性）；
- 一步广义有效进张：对每种公开未见补牌，是否降低下一状态最优弃牌后的向听；
- 两步形状改善代理：补牌后最佳弃牌的最小向听及改善牌面总公开剩余数；
- hand_value、flexibility、公开discard danger；
- 被选候选与第二候选差值；
- 终局s0分数、胡/自摸、花猪，仅作为事后分层标签，不进入运行时输入。

采集输出只写统计摘要和必要的匿名聚合，不新增大规模完整trace。三个数据集必须使用同一代码、配置和字段定义。

## 筛选门禁

- 候选特征必须在三个数据集的覆盖率、排序变化方向和与结果分层关系上同方向；
- 不允许用主集选阈值后再宣称主集为验证集；
- 若没有特征通过，停止于分析报告，不实现业务代码；
- 若通过，另立F0055规格，经批准后才实现100/1000/多数据集A/B。

## 批准记录

用户指令“执行任务1-6”明确授权完成联合指标、密集特征采集、三数据集筛选并仅在同方向时继续实现。本规格据此批准只读采集；不授权绕过F0055直接修改业务策略。
