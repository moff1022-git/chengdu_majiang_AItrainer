## 调参工作流（建议）

1. 勾选本表一条 ID → 改 `hand_predict.py` 常量或分支。  
2. `tools/eval_hand_predict.py --games 20 --seed 42` 快测 → 对比 mid/late/top1。  
3. 确认后 `--games 100` 固化 → 更新本表「当前系数」列。  
4. 触发语示例：`调 F0010 规则 C4b` / `关掉 D6 配额` / `H3 阈值改 5`。
