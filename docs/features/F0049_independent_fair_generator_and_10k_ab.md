# F0049 独立公平生成器恢复与 gang .50/.55 万局验证

Status: Done

## 目标

恢复 clean-source 中被排除的公平牌局生成能力，生成两个不同种子的独立公平数据集，并把 `.50/.55` 配对样本从2000局扩大到至少10000局。

## 生成合同

- CLI显式接收 `--test-id --seed --games --output`；相同参数逐字节复现；
- 每局庄家按局号轮换；每局从16个由 seed/test-id/game-index/candidate-index 派生的候选牌墙中确定性选择；
- 候选评分最小化四座初始手牌的花色数量离散、对子离散、终张/中张离散，并对连续窗口累计花色偏差增加配额惩罚；不得读取AI运行结果；
- 输出完整108张 `wall_order`、四座14/13/13/13张 `initial_hands`、dealer、candidate_index、score；
- manifest包含算法版本、seed、候选数、数据SHA、生成参数；
- 校验108张守恒、手牌长度、发牌前缀一致、dealer轮换、SHA与重复生成一致。

## A/B范围

- 生成两个不同seed的公平数据集，各4000局；与既有主集/held-out合计10000局；
- 只比较gang `.50/.55`，其他参数沿用F0048；s1-s3 novice_balanced；
- 为性能只保存终局记录；失败必须为0；
- 统计每数据集总分方向、配对均分差、95% bootstrap CI、标准差、最差5%均分、胡牌/自摸/花猪/点炮。

## 晋级与后续

- 仅当每个独立数据集 `.55-.50` 总分均>0且合并10000局配对bootstrap CI下界>0，才允许另立规格修改正式预设；
- 否则正式预设不变，并进入基于杠后期望收益的机制设计，不实现未经批准的新模型。

## 验收

- 生成器测试通过；两个数据集各4000条且不同SHA、可复现；
- 四组运行各4000/4000；总配对样本10000；
- 输出结论、LATEST、changelog和后续机制规格（若门槛失败）。

## 验收结果

生成器测试和两个4000局数据集均通过；四组A/B均4000/4000成功，总配对样本10000。合并CI `[-.0011,.0104]`，seed-a方向为负，未达到晋级门槛；正式预设保持不变，后续转入F0050 Draft。
