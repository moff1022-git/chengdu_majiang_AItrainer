# F0051 公开概率杠后补牌枚举

Status: Rejected after validation

## 背景

F0050失败的根因是把杠前静态speed当作杠后状态。本功能对27种可能补牌进行显式状态转移，并按 `PublicBelief.unseen_counts` 加权，不读取真实未来牌墙。

## 状态转移

- 暗杠：从暗手移除同面4张，新增 `an_gang` meld；
- 加杠：从暗手移除同面1张，将已有pong视为 `jia_gang`；
- 明杠：从暗手移除同面3张，新增 `ming_gang` meld；
- 对27种面分别补入1张；公开未见余数为0的面权重为0；
- 每个补牌状态重新计算向听、听牌进张、定缺牌数；不访问 `wall_order`、真实下一张、对手暗手。

## 评分

输出 `expected_shanten_delta`、`tenpai_probability`、`win_probability`、`dingque_probability`。调整量限定为小幅门禁：

`bonus = 0.06*tenpai + 0.10*win - 0.08*dingque - 0.06*max(0, expected_delta) + 0.02*gang_preference`

该模型不把即时杠收入作为主正项，避免F0050过度杠。

## 门禁

1. 纯函数与禁止未来输入测试；
2. 已知关键分叉局验证枚举可复现；
3. 同前100局总分、胡牌、花猪不得劣于旧 `.50`；
4. 通过后才运行1000局完整trace；否则回滚业务实现并保留证据。

## 验证与回滚

纯函数/禁止未来输入及相关回归共13项通过。固定同前100局结果：枚举模型82分、32胡、16自摸、4花猪；旧 `.50/.55` 均91分、34胡、17自摸、4花猪。仍劣于门禁，未运行1000局，业务实现与专项测试已回滚。

偏差根因：模型对补牌后14张状态直接调用shanten，虽然shanten内部会找最优弃牌，但枚举没有保留“最佳弃牌是什么、弃后进张数和风险”，评分只依赖粗粒度向听类别，无法区分同向听下的有效进张质量，仍会错误改变临界杠决策。
