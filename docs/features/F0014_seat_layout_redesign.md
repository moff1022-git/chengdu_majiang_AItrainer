## 0. 产品决议（修订 2026-07-20）

| ID | 决议 |
|----|------|
| **T1** | **视觉风格统一**：主窗（pygame）+ 人类座位窗 + AI 座位窗 **同一主题资产与色板**（见 §1） |
| **T2** | **设置不砍**：人类窗与 AI 窗均 **保留现有设置条/折叠设置中的全部开关与选项**（见 §2）；完整/精简只改 **信息区显隐与默认尺寸**，不删控件 |
| **T3** | **布局必须「完整显示」**：初始 `WindowPlan` 保证目标配置下 **主窗 + 全部座位窗无重叠裁切**（在工作区 ≤2K 约定内，见 F0001） |
| **T4** | **两套标准布局**（均须设计图 + 可实现）：**V1** = 1 人类 **完整** + 3 AI **精简** + 主窗；**V2** = **2–4** 人类 **精简** + 剩余 AI **精简** + 主窗 |
| **T5** | 弃牌权威仍在主桌；精简座位可不画本家弃牌网格，但 **不得** 为省空间删除设置条 |
| **T6** | 多 human 引擎协议可后置实现，但 **布局几何与 UI 规格须先支持 2–4 人类精简同时完整显示**（T4-V2） |
| **T7** | **同窗延展切换**：完整 ↔ 精简 **不换窗、不换进程、不重建 OS 窗口**；仅 **同一座位窗** 改变内容区显隐 + **窗口高度（可宽度）延展/收缩** |
| **T8** | **设计图一体**：独立窗示意与布局示意必须用 **同一视觉组件包**（同标题栏、同设置条、同色板、同牌面比例）；禁止「组件图一套皮肤、布局图另一套皮肤」 |

附加：

- 牌面优先：压缩顺序 = 先藏可选信息区（完整才有的 B16 等）→ 再略缩非手牌 → **最后**才缩手牌。  
- 运行时仍可拖动；可选「重置布局」回到 V1/V2 初始 plan。  
- 默认模式：V1 人类 **完整**；V2 人类 **精简**；AI 默认 **精简**。  
- 平面 2D；主程序与座位窗 **独立进程**，但 **各自** full/hand 是同进程同窗延展。

## 1. 风格一致性（对齐 assets）

### 1.1 权威来源

| 来源 | 用途 |
|------|------|
| `assets/ASSETS.md` | 命名、尺寸约定、主题后缀、无「吃」按钮等产品约束 |
| `assets/palettes/palette_{theme}.png` | 色板卡（翠玉青云 green / 碧海朗月 blue） |
| `assets/backgrounds/bg_table_{theme}.png` | 主桌绿毡/蓝毡底 |
| `assets/tiles/**/tile_*_{theme}.png` | 牌面（270×378 源图，显示按比例缩放） |
| `assets/buttons/btn_*_{theme}.png` | 碰/杠/胡/过/确认/取消（**无吃**） |
| `assets/players/*` | 座位标、头像、庄标 |
| `assets/icons/*` | 设置/音量/退出/分数/剩余 |
| `assets/strategy/*`、`assets/inference/*` | 策略/推理 HUD 元素 |

### 1.2 统一规则

| 规则 | 说明 |
|------|------|
| **同主题** | 一次对局主窗与所有座位窗 `theme` 一致（`green` 或 `blue`） |
| **同色语义** | 桌面深底 `#1A3D2B` 系（green）/ `#0D2744` 系（blue）；金描边强调；牌面白底朱砂万字等 **与 assets 一致** |
| **同控件族** | 操作按钮优先用 `assets/buttons` 图（或同色板矢量近似）；设置条用同色「胶囊开关」风格，与现 seat_window 可读性要求一致 |
| **同中文可读** | CJK 字体回退（F0005）；禁止 Windows-only 字体名导致空白 |
| **禁止风格分裂** | 禁止主窗写实牌桌、座位窗却用完全不同的 Material 灰白皮肤；禁止 AI 窗单独「另一套皮肤」 |

### 1.3 窗体皮肤分层

| 层 | 主窗 MAIN | 座位窗（人/AI 同肤） |
|----|-----------|----------------------|
| 背景 | `bg_table_*` + 既有桌面布局 | 同主题深绿/深蓝面板（`#0d2818` / `#0a1f14` 系，贴色板） |
| 标题 | 局信息 / 控制 | 座位 · 完整|精简 · **设置条** |
| 牌 | assets 牌面 | 同 assets 牌面 |
| 操作 | 主桌既有（若有） | 人类：assets 按钮（**无吃**）；AI：无操作按钮 |

### 1.4 完整/精简：同一视觉系统 + 同窗延展（T7/T8）

#### 1.4.1 禁止的错误形态

| 错误 | 说明 |
|------|------|
| 换窗切换 | 点「完整」打开第二个 OS 窗或换一套完全不同的 chrome |
| 两套皮肤 | full 用圆角金边，hand 用灰白 Material 等不一致 |
| 布局图另起炉灶 | 布局示意图的座位窗与独立设计图认不出来是同一组件 |
| 3D / 透视 | 与平面资产体系冲突 |

#### 1.4.2 正确形态

```
同一 Tk 座位进程 / 同一 root 窗口
        │
        ├─ view_mode = hand  →  隐藏 B16 等 · 高度 H_compact · 设置条与标题不变
        │
        └─ view_mode = full  →  显示 B16 等 · 高度 H_full（向下或向上延展）· 同一标题/设置条
```

| 项 | 规则 |
|----|------|
| 窗口身份 | `seat_window` 一个 root；切换只 `geometry` 高度 + 区域 pack/forget |
| 标题栏 | 完全相同结构；仅分段控件高亮「精简/完整」切换 |
| 设置条 A4–A8 | 位置、样式、控件集合 **不变** |
| 状态行 A3 | 样式不变 |
| 底栏 A12 | 人类始终可有操作区；样式不变 |
| 内容差 | 见 §2 表 Y/D/H；**不是**换皮 |
| 动画 | 可选；非必须。默认瞬时改高度即可 |
| 主窗 | 不参与 full/hand；布局里 MAIN 始终独立进程窗 |

#### 1.4.3 设计组件包（所有示意图强制同一套）

| 组件 | 规格（green 示例） |
|------|-------------------|
| 窗框 | 深底 `#0a1914` 标题栏 + `#143528` 内容；金/浅绿细描边；mac 三色灯或等价 |
| 分段控件 | 胶囊 `[精简\|完整]`，选中实心金/绿，未选描边 |
| 设置芯片 | 圆角条，开=绿底，关=灰底；同一字号 |
| 信息卡 | `#1a2818` / `#0f241c` 扁平面板，2px 高亮边 |
| 牌面 | 奶白扁平面，比例近 1:1.4；**仅万筒条**（设计示意勿用字牌/吃） |
| 按钮 | 扁圆角 碰/杠/胡/过/确认；**禁止「吃」** |
| 表格 HUD | 表头灰绿，行交替略深 |

独立窗图、同窗延展对比图、V1/V2 布局图 **必须共用此组件包**。
