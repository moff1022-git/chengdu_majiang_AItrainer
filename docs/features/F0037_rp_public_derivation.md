# F0037 RP-010/RP-018～RP-022 公共投影派生规格

Status: Done

Approval: 用户于 2026-08-02 指令“那就执行任务1-5”，批准本规格并要求实现。

本规格只允许从当前座位的 PlayerView/公开投影派生 RP，不允许读取完整 RoundState、对手隐藏手牌、真实牌墙顺序或服务器随机流。派生结果用于合法候选内的评估，不扩张合法行动集合。

## 派生合同

- RP-010：从自己的手牌、公开弃牌、公开副露和公开胡牌信息聚合 27 维可见计数；每种牌限制 `0..4`。
- RP-018：等待集合、活牌和概率只使用 RP-010 的未见上界；不使用真实牌墙排列。
- RP-019：对手假设概率只使用公开弃牌/副露事件；概率归一化为 1。
- RP-020：风险仅为公开证据估计，范围 `0..1`，不得标记为真实听牌结果。
- RP-021：从公开牌墙余量或区间估计剩余机会；不可见时必须输出区间或 `null`。
- RP-022：从公开牌墙比例派生 early/middle/late/endgame，阈值单调。

## 安全门禁

派生函数输入类型只接受 `Mapping` 的公开投影；禁止字段包括 `hidden_hand`、`server_hand`、`private_hand`、`concealed_tiles`、`wall_order`、`rng_state`。任何命中立即拒绝。每个 seat 独立调用，不共享其他 seat 的私有 RP。

## 验收

1. 同一公开投影确定性相同；不同 seat 的私有手牌不进入输入。
2. 可见牌计数、活牌、概率、风险均在规定范围。
3. 隐藏字段输入被拒绝；派生结果不包含隐藏字段。
4. 派生只影响 RP，不改变合法行动集合和 engine 计分。
