# F0053 仅暗杠公开信息两层门禁

- 状态：Rejected after multi-dataset validation
- 日期：2026-08-04
- 前置：F0052（Rejected after validation）

## 背景与目标

F0052对所有杠型统一施加两层Expectimax，1000局较Expert低48分。逐手审计表明主要风险是明杠与碰只有固定 `0.004` 分差，细小代理调整会翻转动作并产生极端尾部；暗杠两处分叉净+16。F0053验证“仅暗杠使用两层门禁，明杠和加杠保持旧机制”。

## 范围

- 复用F0052公开未见补牌→最佳合法弃牌的两层纯函数。
- 评分调整仅在 `GANG_AN` 使用。
- `GANG_MING`、`GANG_JIA`严格保持 `0.12 * gang_preference`。
- 定缺强制、向听、有效进张、危险度、确定性和信息边界沿用F0052。
- 不修改正式人格参数、引擎规则或配置schema。

## 验收与门禁

- 单测覆盖三种杠：暗杠会调用门禁，明杠/加杠得分与旧机制完全一致。
- 固定100局必须不劣于旧 `.50`：总分>=91、胡牌>=34、花猪<=4。
- 通过后运行同一1000局完整trace；必须总分严格超过Expert的282且trace 1000/1000完整，才进入seed-a/seed-b。
- 独立数据集必须方向一致且合并结果具有稳定优势，才允许另立正式机制更新规格。

## 回滚

移除暗杠门禁调用及纯函数/专项测试即可恢复旧机制；实验数据保留。

## 批准记录

用户指令“执行任务1-6”授权完成分叉分析后，在公开信息可可靠区分时继续F0053实现与门禁。本规格严格限定在该任务范围，据此进入Approved。

## 验证结果

- 定向测试：13 passed。
- 固定100局：91分/34胡/17自摸/4花猪，与旧 `.50` 完全一致。
- 主固定1000局：293分，较旧 `.50`/Expert的282分高11分；完整trace 1000/1000。
- seed-a 4000局：757分，旧 `.50` 776分，差-19。
- seed-b 4000局：-455分，旧 `.50` -453分，差-2。
- 合并9000局：-10分，均分差-0.00111，bootstrap 95% CI约[-0.00867,+0.00667]。

独立数据集均未保持正向，稳定性门禁失败。业务实现和专项测试已回滚，正式人格未修改，运行证据保留。
