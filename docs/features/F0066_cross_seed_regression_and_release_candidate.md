# F0066 Nonhuman 跨种子防回退与发布候选

- 状态：Done
- 日期：2026-08-05
- 依赖：F0057、F0063、F0065

## 背景与动机

F0065 已在一个新盲测数据集上证明 Nonhuman 相对 Expert 的配对优势，并完成四阵容分层验证。本功能把既有独立固定数据集证据合并为跨种子结论，深化候选分差与向听/定缺/公开进张的只读关联审计，并将可机器判定的防回退门禁和可校验发布候选固化，避免后续只凭单次总分判断。

## 范围

### In Scope

1. 复用未因结果选择的独立固定数据集；按 test_id、数据 SHA、game_id 配对 Nonhuman/Expert，输出逐数据集和合并统计。
2. F0057 只读审计按 shanten、dingque_tiles、ukeire_public_count、候选最高/次高分差分层；只描述关联，不声称观察数据已证明因果。
3. 新增纯离线防回退检查器：验证输入证据 schema、数据集独立性、零失败、配对完整性、各数据集方向、合并 bootstrap CI、胡牌/自摸/花猪/点炮护栏。
4. 新增单元测试与固定小样本，CI 不依赖 `data/` 大文件。
5. 生成 `0.3.1` clean source/evidence 候选归档、manifest 和 SHA-256；不修改 `version.py`、不创建或覆盖正式 tag/Release。

### Out of Scope

- 不修改 Nonhuman 或 Expert 人格参数。
- 不把相关性统计表述为因果识别。
- 不重新执行已经完成的四阵容 8×1000 局。
- 不提交牌局、trace、虚拟环境或构建缓存。
- 不发布新的正式 SemVer；若要发布新版本，另立发版规格。

## 方案

### 跨种子证据

- 输入为每组终局结果及其运行配置/报告；要求相同数据集内双方 game_id 集合一致。
- 每个数据集报告总分差、配对均分差、胜/平/负局数及固定 seed bootstrap 95% CI。
- 合并统计保留 dataset_id 分层；bootstrap 以 game_id 配对差为抽样单位，并记录随机 seed 与迭代次数。
- 旧调参数据只作历史背景；正式防回退基线优先使用 F0064/F0065 的盲测数据。

### F0057 关联审计

- 使用决策时已记录字段，不读取隐藏牌或未来事件。
- 输出字段覆盖率、分位数/离散桶、每桶候选分差与被选候选排名变化率；按花猪/非花猪、向听、定缺牌数量和公开进张分层。
- 缺字段明确标记 `insufficient_evidence`，不得用零填充。

### 防回退门禁

- `PASS` 必须同时满足：证据可解析、数据集 SHA 唯一且完整、每组成功数等于请求数、失败为0、双方 game_id 完全配对、合并均分差大于0、bootstrap 95% CI 下界大于0。
- 分项护栏默认报告：胡牌、自摸不得出现超过预设容差的下降，花猪、点炮不得出现超过容差的上升；容差和阈值必须写入输入 policy，禁止隐藏默认值改变结论。
- 任一结构/完整性问题为 `ERROR`，统计门槛未满足为 `FAIL`；退出码分别为2和1，PASS为0。

### 发布候选

- `releases/v0.3.1-f0066-rc-source/`：Git 跟踪的业务源代码、配置、文档、测试和必要资源；排除 `.git`、`data`、`releases`、`backup`、虚拟环境、缓存、日志和构建目录。
- `releases/v0.3.1-f0066-rc-evidence/`：F0065/F0066摘要、配置/提交信息、测试与CI结果，不包含完整牌局或trace。
- 两个目录均生成排序稳定的 manifest（相对路径、大小、SHA-256），再生成压缩包及顶层校验文件。
