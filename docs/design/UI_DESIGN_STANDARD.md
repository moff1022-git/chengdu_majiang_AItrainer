## 1. 设计决议（本版）

| # | 决议 |
|---|------|
| R1 | **仅横屏布局**；不另做竖屏拓扑 |
| R2 | 按游戏模式分三种布局：**A / B / C**（见 §2） |
| R3 | **MAIN** 固定：占 **布局有效区** 面积 **25%**，**左下** |
| R4 | **人类完整** 固定：占布局有效区 **25%**；落位见 §5 |

| R9 | **窗口大小一致性**：同档 MAIN/人类/AI 外框在布局 A/B/C 间一致 |

## 2. 布局定义（仅横屏 · 按游戏模式）

工作区宽 `W`、高 `H`（预期 `W ≥ H`）。

| 布局 ID | 游戏模式 | 人类 | AI | 座位窗 |
|---------|----------|------|-----|--------|
| **A** | 3 AI + 1 人类 | 1 | 3 | 4 |
| **B** | 2 AI + 2 人类 | 2 | 2 | 4 |
| **C** | 4 AI + 0 人类 | 0 | 4 | 4 |

MAIN 始终 1 个。  
**Out of Scope**：3 人类局及其它未列表配置。

### 2.1 配置判定

```text
n_human = count(play)
n_ai    = num_players - n_human

if n_human == 1 and n_ai == 3 → 布局 A
if n_human == 2 and n_ai == 2 → 布局 B
if n_human == 0 and n_ai == 4 → 布局 C
else → 无标准 plan
```

## 3. 布局有效区（85% 画布）与窗尺寸基准

### 3.1 封顶与画布

```text
工作区 Work：W × H，原点 (Ox, Oy)

# 1) 默认 plan 封顶（2160p）
Wc = min(W, 3840)
Hc = min(H, 2160)

# 2) 布局总面积 = 0.85 × 封顶工作区面积（同比例、居中）
s = sqrt(0.85) ≈ 0.922
Lw = round(Wc * s)
Lh = round(Hc * s)
Ox_c = Ox + (W - Lw) // 2
Oy_c = Oy + (H - Lh) // 2

# 窗百分比与落位一律相对画布 (Ox_c, Oy_c, Lw, Lh)
```

| 档 | 工作区参考 | 布局画布 Lw×Lh | 面积比 |
|----|------------|----------------|--------|
| **720p** | 1280×720 | **1180×664** | ≈0.850 |
| **1080p** | 1920×1080 | **1770×996** | ≈0.850 |
| **2160p** | 3840×2160 | **3540×1991** | ≈0.850 |
| **>2160p** | 更大 | **同 2160p 画布与 §8 窗表** | 默认不增大 |

### 3.2 完整模式外框（相对画布 · A/B/C 共用）

画布面积 `Sc = Lw × Lh` = 100%。

| 窗类型 | 面积占比 | 默认外框 |
|--------|----------|----------|
| **MAIN** | **25%** | `Wm×Hm`，`Wm=⌊Lw/2⌋`，`Hm=⌊Lh/2⌋` |
| **人类 Full** | **25%** | 与 MAIN 同 `Wm×Hm`；右列可贴齐 `Wm2=Lw-Wm` |
| **AI Full** | **6.25%** | `Wa×Ha`，`Wa=⌊Lw/4⌋`，`Ha=⌊Lh/4⌋`；**y 顶对齐** |

```text
Wm = Lw // 2
Hm = Lh // 2
Wm2 = Lw - Wm
Hm2 = Lh - Hm
Wa = Lw // 4
Ha = Lh // 4
# AI.y = 上半带顶；若 bottom 触 MAIN 则上移（保持 Ha，不拔高）
```

### 3.3 窗口大小一致性

| 规则 | 要求 |
|------|------|
| MAIN | 同档 A/B/C **同一外框** |
| 人类 Full | 同档所有人类窗相同，且与 MAIN **同规格** |
| AI Full | 同档所有 AI 相同（与布局 A/B/C **无关**，共用 Wa×Ha） |
| 精简 | 宽 = 完整宽//2，高不变，左锚固定 |

### 3.4 画布分区示意

```text
布局画布 Lw × Lh（居中于工作区）

┌─────────────────┬─────────────────┐
│  左上 ≈25%      │  右上 ≈25%      │
├─────────────────┼─────────────────┤
│  左下 MAIN 25%  │  右下 人类 25%  │
└─────────────────┴─────────────────┘
```

## 6. AI 完整模式

| 项 | 规格 |
|----|------|
| 面积 | 画布 **6.25%**（宽 1/4 × 高 1/4） |
| 外框 | §8 `Wa×Ha`（A/B/C 相同；**顶对齐**，不放大高） |
| 数量 | A×3 · B×2 · C×4 |

### 6.1 布局 A — 上半横向均分 ×3

```text
# 原尺寸 + 顶对齐（禁止上半区垂直居中）
Ha = Lh // 4
AI.y = Oy_c                    # 贴上沿
# 若 AI.bottom > MAIN.y - DECORATION_PAD - GAP → 仅上移 y，保持 Ha
total_w = 3*Wa; gap_free = Lw - total_w
g_ai = max(0, gap_free // 4); margin_x = (gap_free - 2*g_ai) // 2
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai); w,h = Wa,Ha
```

```text
┌── AI ──┬── AI ──┬── AI ──┐
├────────┴───┬────┴────────┤
│ MAIN 25%   │ 人类1 25%   │
└────────────┴─────────────┘
```

### 6.2 布局 B — 左上横向均分 ×2

```text
box_w, box_h = Wm, Hm
total_w = 2*Wa; gap_free = box_w - total_w
g_ai = max(0, gap_free // 3); margin_x = (gap_free - g_ai) // 2
band_y = Oy_c + max(0, (box_h - Ha) // 2)
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai); AI[i].y = band_y
```

```text
┌── AI ──┬── AI ──┬ 人类2 25% ─┐
├────────┴───┬────┴────────────┤
│ MAIN 25%   │ 人类1 25%       │
└────────────┴─────────────────┘
```

### 6.3 布局 C — 上半横向均分 ×4

```text
total_w = 4*Wa; gap_free = Lw - total_w
g_ai = max(0, gap_free // 5); margin_x = (gap_free - 3*g_ai) // 2
band_y = Oy_c + max(0, (Hm - Ha) // 2)
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai)
```

```text
┌─ AI ─┬─ AI ─┬─ AI ─┬─ AI ─┐
├──────┴──┬───┴──────┴──────┤
│ MAIN 25%│  （右下空）       │
└─────────┴─────────────────┘
```

右下不自动放大 MAIN。

## 8. 三档默认窗口尺寸（最小默认 · px）

### 8.1 原则

| 原则 | 说明 |
|------|------|
| 默认 = 最小 | §8.2 表列为 S=1 下限 |
| 可放大 | 统一 `S≥1` 等比（§8.4） |
| >2160p | 默认 **锁定 2160p 行** |
| 中间分辨率 | 对实际 W×H 走 §3.1–3.2，或取不大于当前屏的最近档 |

### 8.2 完整 / 精简外框（布局 A/B/C 共用）

| 档 | 画布 Lw×Lh | MAIN = 人类 Full | AI Full | 人类 Compact | AI Compact |
|----|------------|------------------|---------|--------------|------------|
| **720p** | **1180×664** | **590×332** | **295×166** | **295×332** | **147×166** |
| **1080p** | **1770×996** | **885×498** | **442×249** | **442×498** | **221×249** |
| **2160p** | **3540×1991** | **1770×995** | **885×497** | **885×995** | **442×497** |

面积校验：MAIN/人类 = 25%；AI ≈ 6.25%。  
**MAIN 与人类完整窗高度必须一致**（同 `Hm` / 同 cap）。

### 8.3 1080p 落位速查（相对画布原点）

| 窗 | 布局 A | 布局 B | 布局 C |
|----|--------|--------|--------|
| MAIN 885×498 | (0, 498) | (0, 498) | (0, 498) |
| 人类1 885×498 | (885, 498) 右下 | (885, 498) 右下 | — |
| 人类2 885×498 | — | (885, 0) 右上 | — |
| AI 442×249 | 上半横均分 ×3 | 左上横均分 ×2 | 上半横均分 ×4 |

绝对坐标：`+= (Ox_c, Oy_c)`。

### 8.4 等比放大

```text
S ≥ 1（默认 / 重置 S = 1）
画布与各窗宽高 × S 后按 §5–§6 重落位
放大后外包 ⊆ 实际工作区；否则夹紧 S
精简：Full×S 后 w_c = floor(w/2)
```

### 8.5 720p / 2160p 落位

与 §5–§6 相同，将 `Wm,Hm,Wa,Ha,Lw,Lh` 换成 §8.2 对应行即可。  
例 720p：MAIN 左下 `(0, 332)` 相对画布，人类1 右下 `(590, 332)`。

## 9. 验收标准

- [ ] 画布面积 / 封顶工作区 ∈ **[0.84, 0.86]**  
- [ ] 仅布局 **A / B / C**（横屏）  
- [ ] MAIN 画布 25%、左下；三布局同档外框一致  
- [ ] 人类 25%、与 MAIN 同规格；A/B 落位正确  
- [ ] AI 顶对齐、不压 MAIN；同档三布局外框算法一致；数量 A3/B2/C4  
- [ ] §8.2 表与公式一致（≤2px 取整）  
- [ ] 默认 S=1 最小；>2160p 用 2160p 表
