## 2. 布局定义（仅横屏 · 按游戏模式）

工作区宽 `W`、高 `H`（预期 `W ≥ H`）。

| 布局 ID | 游戏模式 | 人类 | AI | 座位窗 |
|---------|----------|------|-----|--------|
| **A** | 3 AI + 1 人类 | 1 | 3 | 4 |
| **B** | 2 AI + 2 人类 | 2 | 2 | 4 |
| **C** | 4 AI + 0 人类 | 0 | 4 | 4 |
| **D** | 1 AI + 3 人类 | 3 | 1 | 4 |

MAIN 始终 1 个。  
**Out of Scope**：竖屏拓扑；4 人类专属拓扑（可选后续）；非 4 座牌局。

### 2.1 配置判定

```text
n_human = count(play)
n_ai    = num_players - n_human

if n_human == 1 and n_ai == 3 → 布局 A
if n_human == 2 and n_ai == 2 → 布局 B
if n_human == 0 and n_ai == 4 → 布局 C
if n_human == 3 and n_ai == 1 → 布局 D
else → 无标准 plan（启动失败并提示）
```

## 3. 布局有效区（85% 画布）与窗尺寸基准

### 3.1 封顶与画布

```text
工作区 Work：W × H，原点 (Ox, Oy)

# 1) 默认 plan 封顶（2160p）
Wc = min(W, 3840)
Hc = min(H, 2160)

# 2) 布局总面积 = 0.85 × 封顶工作区面积（同比例、居中）
s = sqrt(0.85) ≈ 0.922
Lw = round(Wc * s)
Lh = round(Hc * s)
Ox_c = Ox + (W - Lw) // 2
Oy_c = Oy + (H - Lh) // 2

# 窗百分比与落位一律相对画布 (Ox_c, Oy_c, Lw, Lh)
```

| 档 | 工作区参考 | 布局画布 Lw×Lh | 面积比 |
|----|------------|----------------|--------|
| **720p** | 1280×720 | **1180×664** | ≈0.850 |
| **1080p** | 1920×1080 | **1770×996** | ≈0.850 |
| **2160p** | 3840×2160 | **3540×1991** | ≈0.850 |
| **>2160p** | 更大 | **同 2160p 画布与 §8 窗表** | 默认不增大 |

### 3.2 完整模式外框（相对画布）

画布面积 `Sc = Lw × Lh` = 100%。

**布局 A / B / C（2×2 四分模型）**

| 窗类型 | 面积占比 | 默认外框 |
|--------|----------|----------|
| **MAIN** | **25%** | `Wm×Hm`，`Wm=⌊Lw/2⌋`，`Hm=⌊Lh/2⌋` |
| **人类 Full** | **25%** | 与 MAIN 同规格；右列 `Wm2=Lw-Wm` |
| **AI Full** | **6.25%** | `Wa×Ha`，`Wa=⌊Lw/4⌋`，`Ha=⌊Lh/4⌋`；**y 顶对齐** |

```text
Wm = Lw // 2
Hm = Lh // 2
Wm2 = Lw - Wm
Hm2 = Lh - Hm
Wa = Lw // 4
Ha = Lh // 4
# AI.y = 带顶；若 bottom 触 MAIN 则仅上移 y，保持 Ha
```

**布局 D（3H+1AI）**：见 §5.4 / §6.4 — **顶带 AI + body 2×2**，MAIN/人类边长取 body 行高/列宽（**不必** 25%）。

### 3.3 窗口大小一致性

| 规则 | 要求 |
|------|------|
| MAIN | 同档 A/B/C **同一外框**；D 用 body 底行列 |
| 人类 Full | A/B：与 MAIN 同规格；D：同排同高 |
| AI Full | 共用 Wa×Ha；D 仅 1 个 |
| 精简 | 宽 = 完整宽//2，高不变，左锚固定 |

### 3.4 画布分区示意

```text
布局画布 Lw × Lh（居中于工作区）

┌─────────────────┬─────────────────┐
│  左上 ≈25%      │  右上 ≈25%      │
├─────────────────┼─────────────────┤
│  左下 MAIN 25%  │  右下 人类 25%  │
└─────────────────┴─────────────────┘
```

## 5. 人类完整模式

| 项 | 规格 |
|----|------|
| 面积 | 画布 **25%** |
| 外框 | `Wm×Hm`（右列可用 `Wm2`） |

### 5.1 布局 A — 玩家1 **右下**

```text
Human1: x=Ox_c+Wm, y=Oy_c+(Lh-Hm), w=Wm2, h=Hm
```

### 5.2 布局 B — 玩家1 **右下**，玩家2 **右上**

```text
Human1: x=Ox_c+Wm, y=Oy_c+(Lh-Hm), w=Wm2, h=Hm
Human2: x=Ox_c+Wm, y=Oy_c,         w=Wm2, h=Hm
```

### 5.3 布局 C — 无人类窗

### 5.4 布局 D — 3 人类（body 四分 · 见 F0020）

```text
Ha = Lh // 4
body_top = Oy_c + Ha + GAP
body_h = Lh - Ha - GAP
row_h = body_h // 2
row_h2 = body_h - row_h
col_w = Lw // 2
col_w2 = Lw - col_w

H[1] 左上 body: x=Ox_c,         y=body_top,         w=col_w,  h=row_h
H[2] 右上 body: x=Ox_c+col_w,    y=body_top,         w=col_w2, h=row_h
H[0] 右下 body: x=Ox_c+col_w,    y=body_top+row_h,   w=col_w2, h=row_h2
MAIN 左下 body: x=Ox_c,          y=body_top+row_h,   w=col_w,  h=row_h2
```

`H[i]` = `human_seats` 列表第 i 个座位（按 `--players` 中 human 出现顺序）。

```text
┌──────────── AI 顶带 ────────────┐
├──── H[1] ────┬──── H[2] ───────┤
├──── MAIN ────┼──── H[0] ───────┤
└──────────────┴──────────────────┘
```

## 6. AI 完整模式

| 项 | 规格 |
|----|------|
| 面积 | 画布 **6.25%**（宽 1/4 × 高 1/4） |
| 外框 | §8 `Wa×Ha`（**顶对齐**，不放大高） |
| 数量 | A×3 · B×2 · C×4 · **D×1** |

### 6.1 布局 A — 上半横向均分 ×3

```text
# 原尺寸 + 顶对齐（禁止上半区垂直居中）
Ha = Lh // 4
AI.y = Oy_c                    # 贴上沿
# 若 AI.bottom > MAIN.y - DECORATION_PAD - GAP → 仅上移 y，保持 Ha
total_w = 3*Wa; gap_free = Lw - total_w
g_ai = max(0, gap_free // 4); margin_x = (gap_free - 2*g_ai) // 2
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai); w,h = Wa,Ha
```

```text
┌── AI ──┬── AI ──┬── AI ──┐
├────────┴───┬────┴────────┤
│ MAIN 25%   │ 人类1 25%   │
└────────────┴─────────────┘
```

### 6.2 布局 B — 左上横向均分 ×2

```text
# 左上象限内顶对齐（禁止垂直居中压住 MAIN）
box_w, box_h = Wm, Hm
total_w = 2*Wa; gap_free = box_w - total_w
g_ai = max(0, gap_free // 3); margin_x = (gap_free - g_ai) // 2
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai)
AI[i].y = Oy_c
AI[i].w,h = Wa, Ha
# 若 AI.bottom > MAIN.y - DECORATION_PAD - GAP → 仅上移（保持 Ha）
```

```text
┌── AI ──┬── AI ──┬ 人类 H[1] 25% ─┐
├────────┴───┬────┴────────────────┤
│ MAIN 25%   │ 人类 H[0] 25%       │
└────────────┴─────────────────────┘
```

### 6.3 布局 C — 上半横向均分 ×4

```text
total_w = 4*Wa; gap_free = Lw - total_w
g_ai = max(0, gap_free // 5); margin_x = (gap_free - 3*g_ai) // 2
AI[i].x = Ox_c + margin_x + i*(Wa+g_ai); AI[i].y = Oy_c
```

```text
┌─ AI ─┬─ AI ─┬─ AI ─┬─ AI ─┐
├──────┴──┬───┴──────┴──────┤
│ MAIN 25%│  （右下空）       │
└─────────┴─────────────────┘
```

右下不自动放大 MAIN。

### 6.4 布局 D — 顶带 ×1

```text
AI.x = Ox_c          # 默认左对齐；可选水平居中 (Lw-Wa)//2
AI.y = Oy_c
AI.w,h = Wa, Ha
# 不进入 body；与 H[1]/H[2] 无重叠
```

## 8. 三档默认窗口尺寸（最小默认 · px）

### 8.1 原则

| 原则 | 说明 |
|------|------|
| 默认 = 最小 | §8.2 表列为 S=1 下限 |
| 可放大 | 统一 `S≥1` 等比（§8.4） |
| >2160p | 默认 **锁定 2160p 行** |
| 中间分辨率 | 对实际 W×H 走 §3.1–3.2，或取不大于当前屏的最近档 |

### 8.2 完整 / 精简外框（布局 A/B/C）

| 档 | 画布 Lw×Lh | MAIN = 人类 Full | AI Full | 人类 Compact | AI Compact |
|----|------------|------------------|---------|--------------|------------|
| **720p** | **1180×664** | **590×332** | **295×166** | **295×332** | **147×166** |
| **1080p** | **1770×996** | **885×498** | **442×249** | **442×498** | **221×249** |
| **2160p** | **3540×1991** | **1770×995** | **885×497** | **885×995** | **442×497** |

面积校验（A/B/C）：MAIN/人类 = 25%；AI ≈ 6.25%。  
**MAIN 与同排人类完整窗高度必须一致**。

**布局 D（1080p 示例，`GAP=8`）**

| 窗 | 约尺寸 | 相对画布原点 |
|----|--------|--------------|
| AI | 442×249 | (0, 0) 顶带左 |
| H[1] | 885×369 | (0, 257) |
| H[2] | 885×369 | (885, 257) |
| MAIN | 885×370 | (0, 626) |
| H[0] | 885×370 | (885, 626) |

（`body_h = 996-249-8 = 739`；`row_h=369`，`row_h2=370`。）

### 8.3 1080p 落位速查（相对画布原点 · A/B/C）

| 窗 | 布局 A | 布局 B | 布局 C |
|----|--------|--------|--------|
| MAIN 885×498 | (0, 498) | (0, 498) | (0, 498) |
| 人类 H[0] | (885, 498) 右下 | (885, 498) 右下 | — |
| 人类 H[1] | — | (885, 0) 右上 | — |
| AI 442×249 | 上半横均分 ×3 | 左上横均分 ×2 顶对齐 | 上半横均分 ×4 |

绝对坐标：`+= (Ox_c, Oy_c)`。布局 **D** 见 §5.4 / §8.2 表。

### 8.4 等比放大

```text
S ≥ 1（默认 / 重置 S = 1）
画布与各窗宽高 × S 后按 §5–§6 重落位
放大后外包 ⊆ 实际工作区；否则夹紧 S
精简：Full×S 后 w_c = floor(w/2)
```

### 8.5 720p / 2160p 落位

与 §5–§6 相同，将 `Wm,Hm,Wa,Ha,Lw,Lh` 换成 §8.2 对应行即可。  
例 720p：MAIN 左下 `(0, 332)` 相对画布，人类1 右下 `(590, 332)`。

## 9. 验收标准

- [ ] 画布面积 / 封顶工作区 ∈ **[0.84, 0.86]**  
- [ ] 布局 **A / B / C / D**（横屏）  
- [ ] A/B/C：MAIN 25% 左下；人类 25% 与 MAIN 同规格  
- [ ] B：H[0] 右下、H[1] 右上；AI×2 左上顶对齐  
- [ ] D：AI 顶带；body 2×2 = H[1]/H[2]/MAIN/H[0]；无重叠  
- [ ] AI 顶对齐、不压 MAIN；数量 A3/B2/C4/D1  
- [ ] §8.2 与公式一致（≤2px 取整）  
- [ ] 默认 S=1 最小；>2160p 用 2160p 表
