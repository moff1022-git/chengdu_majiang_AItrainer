## 1. 目标与范围

### 1.1 目标

规定人类操作窗内：

1. **左右结构**及折叠行为  
2. **左侧操作区**纵向分区与占比  
3. **右侧扩展区**弃牌 / 对手 HUD 占比  
4. 各区信息职责（清单级）

### 1.2 In Scope

- play 模式客户区几何与区域命名  
- 折叠扩展区时的宽度变化  
- 完整模式默认展开扩展区  

### 1.3 Out of Scope

- AI watch 窗布局（另文）  
- 主窗外框 / 多窗 A·B·C 落位（UI_DESIGN_STANDARD）  
- 引擎协议  
- 本轮不写业务代码（出图另令）

## 2. 总体：左右结构

客户区宽 `Cw`、高 `Ch`。

```text
┌─────────────────────────────────┬──────────────────┐
│                                 │                  │
│     玩家操作区 OP               │  扩展显示区 EXT  │
│           67%                   │   33%（可折叠）  │
│                                 │                  │
└─────────────────────────────────┴──────────────────┘
```

| 区域 ID | 名称 | 默认宽度占比 | 高度 | 可折叠 |
|---------|------|--------------|------|--------|
| **OP** | 玩家操作区 | **67%** | 100%·Ch | 否 |
| **EXT** | 扩展显示区 | **33%** | 100%·Ch | **是 → 向左收起隐藏** |

```text
# 展开态
Ow = floor(Cw * 0.67)
Ew = Cw - Ow                    # 吸收余数 ≈ 33%
Ox, Oy = 0, 0
Ex, Ey = Ow, 0
Oh = Eh = Ch

# 折叠态（扩展区隐藏）
Ow_collapsed = Cw               # 操作区占满
Ew_collapsed = 0
EXT 不绘制 / 宽为 0
```

### 2.1 折叠交互

| 项 | 规格 |
|----|------|
| 方向 | 扩展区 **向左** 收起（右缘移向 OP 右缘直至宽为 0） |
| 触发 | 标题栏/OP 右缘 **「扩展 › / ‹」** 按钮；可选快捷键 |
| 动画 | 可选；默认瞬时改宽 |
| 默认 | **展开**（33% 可见） |
| 记忆 | 可选记住用户偏好（实现阶段） |

折叠后 OP 内布局比例 **相对 OP 新宽度重算**，纵向占比不变。

## 3. OP — 玩家操作区（左 67%）

矩形：`(0, 0, Ow, Ch)`。自上而下四段：

```text
┌─────────────────────────────────────┐
│ OP_INFO     玩家信息        1 行    │  固定行高
├─────────────────────────────────────┤
│ OP_STATUS   当前状态        20%     │  左右平分
├─────────────────────────────────────┤
│ OP_PLAY     实时手牌        60%     │  上副露 / 下手牌+操作
├─────────────────────────────────────┤
│ OP_SETTINGS 状态设置        余量    │  固定 2 行（约 20% 量级）
└─────────────────────────────────────┘
```

### 3.1 高度分配

用户给定（**2026-07-21 修订**）：**状态区 20%**、**手牌区 60%**；信息 1 行、设置 2 行。

```text
# 优先保证比例块，行高按内容最小值夹紧
H_info = max(H_ROW, 可选上限)           # 1 行
H_set  = max(2 * H_ROW, …)            # 2 行
H_flex = Ch - H_info - H_set          # 剩余给 20%+60% 基准

# 将 20:60 映射到 H_flex（二者合计 80% 的「内容权重」落在 flex 内）
# 若严格按整窗 Ch：
H_status = floor(Ch * 0.20)
H_play   = floor(Ch * 0.60)
# 则 H_info + H_set 应占约 Ch*0.20；实现时：
#   若 H_info+H_set+H_status+H_play > Ch → 压缩 H_ROW 或略减 H_status/H_play 并保持 20:60
```

**推荐实现（稳健）**：

```text
H_ROW ≈ clamp(round(Ch * 0.04), 28, 40)   # 单行
H_info = H_ROW
H_set  = 2 * H_ROW
rest   = Ch - H_info - H_set
H_status = floor(rest * 0.20 / 0.80)      # 在剩余中按 20:60 分
H_play   = rest - H_status                # 对应 60/80
# 等价：rest 内 status:play = 20:60
```

验收时：**状态区 : 手牌区 ≈ 20 : 60**（相对 flex / 操作区内容权重，允许行高取整误差）。

### 3.2 OP_INFO — 玩家信息显示区（1 行）

| 元素 | 说明 |
|------|------|
| 座位号 | 如 `S0` |
| 角色 | 人类操作 |
| 昵称/标签 | 可选 |
| 定缺色标 | 有则显示 |
| 视图/折叠入口 | 完整\|精简（若启用）、**扩展区折叠钮** |

单行、不换行；过长文本省略号。

### 3.3 OP_STATUS — 当前状态显示区（整区 20% 高 · 左右平分）

```text
┌──────────────────┬──────────────────┐
│ STATUS_L  50%    │ STATUS_R  50%    │
│ 当前打出         │ 局数 / 得分      │
└──────────────────┴──────────────────┘
```

#### 3.3.1 STATUS_L（左半 · 严格 50% 宽）

| 元素 | 说明 |
|------|------|
| 当前打出牌面框 | **高度 = OP_STATUS 高 × 95%**；宽高比固定 **1 : 1.4**（`w = h / 1.4`）；牌面适配框内 |
| 谁打出 | 座位/名称文案（牌框右侧） |
| 牌墙剩余 | 数量 |

#### 3.3.2 STATUS_R（右半 · 严格 50% 宽）

| 元素 | 说明 |
|------|------|
| 当前局数 | 如 第 k / n 局 |
| 当前得分 | 本家分；可选四家缩略 |

```text
STATUS_L.w = floor(Ow * 0.50)   # 或 floor(status_w/2)
STATUS_R.w = status_w - STATUS_L.w
tile_box_h = floor(status_h * 0.95)
tile_box_w = floor(tile_box_h / 1.4)
```

左右各 **严格 50% 宽**，顶底与 OP_STATUS 对齐；实现须用 place/固定宽，禁止 pack 自由伸缩破坏比例。

### 3.4 OP_PLAY — 实时手牌区（60% 高）

内部分 **上 / 下**：

```text
┌─────────────────────────────────────┐
│ PLAY_MELDS   副露区          ~35%   │  占 OP_PLAY 内部
├─────────────────────────────────────┤
│ PLAY_HAND    手牌 + 操作     ~65%   │
│  · 手牌条（主）                      │
│  · 碰/杠/胡/过 等操作条（贴底）      │
└─────────────────────────────────────┘
```

| 子区 | 默认占 OP_PLAY 高 | 内容 |
|------|-------------------|------|
| **PLAY_MELDS** | **约 35%** | 本家副露组（碰/杠；横向，过多换行） |
| **PLAY_HAND** | **约 65%** | **上方**可点选手牌；**下方**操作条 |

#### 3.4.1 手牌

- 大牌面、单行优先，放不下换行（F0006）  
- **位置固定在 OP_PLAY 手牌区底部**（不随副露/推荐内容上下漂移）  
- **手牌间距 = 0**（牌面贴紧）  
- **牌宽**：按区宽 **尽量放大** 且保证 **14 张** 一行完整显示；左右仅留 **小边距**（约区宽 2–3% 合计），居中  
  `tw = floor( (W − side_total) / 14 ) − chrome`，`chrome≈2`；无右侧滚动条占位  
  手牌描边 **薄**（ht=1）

- 点选 / 双击出牌；换三张按索引（F0012）  
- 推荐角标在手牌格上；**可听进张**为 **50% 透明度** 浮动窗，**贴在手牌显示区正上方**，不占流式高度

#### 3.4.2 操作区（碰杠胡过 · 单行）

| 项 | 规格 |
|----|------|
| 位置 | PLAY_HAND **底部**一条，不与手牌抢同一行焦点 |
| 高度 | **单行**（约一行控件高，随窗缩放） |
| 左右 | **严格 50% / 50%** |
| 左半 | **中文提示**，水平/垂直居左（`anchor=w`） |
| 右半 | **操作按钮**；按当前可见按钮数量均分宽度与间隔 |
| 按钮 | **碰 / 杠 / 胡 / 过**（及换三张确认、定缺花色等阶段控件） |
| **吃** | 成都玩法 / `assets` **无吃**；**不实现「吃」按钮** |
| 显隐 | 仅 `action_request` 合法动作时显示可用按钮 |

```text
┌─────────────────────┬─────────────────────┐
│  提示文案（左对齐）   │  [钮][钮][钮]…       │
│       50%           │       50%           │
└─────────────────────┴─────────────────────┘
# 右半：n 个按钮，均分可用宽，等间距
btn_gap = max(2, floor(right_w * 0.04 / max(1, n)))
btn_w   = floor( (right_w - (n+1)*btn_gap) / n )
```

### 3.5 OP_SETTINGS — 状态设置显示区（2 行）

| 行 | 内容示例 |
|----|----------|
| 第 1 行 | **自动开始** 开/关；**对手牌预测** 开/关 |
| 第 2 行 | **出牌推荐 / 推荐标记** 开/关；其它 play 相关开关（可扩展） |

- 两行固定结构，开关为胶囊/勾选，风格与现设置条一致（F0014 元素表 A4–A8 可迁移至此）  
- **不可**因精简模式删除本区（与 F0014「设置不砍」一致时可整区保留）

## 4. EXT — 扩展显示区（右 33%，可折叠）

矩形展开时：`(Ow, 0, Ew, Ch)`。

```text
┌─────────────────────┐
│ EXT_HUD    30%      │  对手状态 HUD
│                     │
├─────────────────────┤
│ EXT_DISC   70%      │  本家弃牌
│                     │
│                     │
└─────────────────────┘
```

```text
H_hud  = floor(Ch * 0.30)
H_disc = Ch - H_hud

EXT_HUD:  y = 0,      h = H_hud
EXT_DISC: y = H_hud,  h = H_disc
宽均为 Ew
```

### 4.1 EXT_HUD — 对手状态（上 30%）

| 元素 | 说明 |
|------|------|
| 对手列表 | 其它三家：座位、定缺、状态、手牌数、副露数、分数 |
| 形态 | 紧凑表或 chip 行；过长区内滚动 |
| 与主窗 | 可与 MAIN SIDE_TOP 信息同源，本窗为操作侧摘要 |

### 4.2 EXT_DISC — 本家弃牌（下 70%）

| 元素 | 说明 |
|------|------|
| 本家弃牌网格 | 牌河；换行；牌面尺寸随 Ew 缩放 |
| 空态 | 「暂无弃牌」提示 |

折叠 EXT 时：本家弃牌以主桌为准（与「精简看主桌弃牌」策略可并存）；展开时以本区为权威本家河。

## 5. 绘制与层级（建议）

5. 折叠按钮（贴 OP/EXT 分界）
