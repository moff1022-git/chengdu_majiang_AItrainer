# Task 19 状态模型

正常：PLANNING -> WAITING_FOR_DESIGN_APPROVAL -> READY_FOR_IMPLEMENTATION -> IMPLEMENTING -> IMPLEMENTED_PENDING_EVIDENCE -> IMPLEMENTED_PENDING_INDEPENDENT_AUDIT -> AUDITED。

异常：任意非 AUDITED -> BLOCKED；IMPLEMENTING 仅因新语义/接口决策退回 WAITING_FOR_DESIGN_APPROVAL；审计缺陷进入 AUDIT_REMEDIATION，修复和证据重建后回到 IMPLEMENTED_PENDING_INDEPENDENT_AUDIT。

子状态只允许 NOT_REQUIRED/NOT_STARTED/IN_PROGRESS/PASS/FAIL/PARTIAL/WAITING_APPROVAL/BLOCKED。阻塞类型与用户规定枚举一致，且 blocking_id 必须可追踪。
