# Nonhuman 任务 1–4 离线分析

基于权重 A/B 最终 1000 局 audit，不重跑、不改正式配置。

- 计划稳定决策 1,058 次，弃牌候选平均分差 0.9667；花猪局关联 45 次。
- 计划重启决策 54,934 次，弃牌候选平均分差 0.7803；花猪局关联 2,505 次，胡牌动作 357 次。
- 将 `big_hand_preference` 离线从 0.8 降至 0.6，可改变 1,614/14,685 次弃牌首选；降至 0.4，改变 3,119 次。说明该参数对路径影响很大，但尚未证明降低后能超过 expert。
- 稳定计划分差反而更大，主要问题是重启状态下计划切换与候选重排，而不是随机平局。
- evaluator 的局部分数未包含自摸付款、终局花猪和对手先胡等结果，当前 trace 不能直接给出可靠的最终收益相关系数。
