# Nonhuman 相较 Expert 差距定位：完整任务进展与目标演变报告

- 日期：2026-08-05
- 范围：F0040–F0058、现有固定牌局终局/steps/audit、跨数据集 A/B
- 当前结论：旧 Nonhuman 的主要差距已完成定位并修正；正式 `nonhuman_optimized` 已在三组固定数据集、合计 9000 局的晋级门禁中稳定超过 Expert 基线，但尚不能声称全局最优。

因此，任务已不再是“旧 Nonhuman 为何输”，而是“已修正参数栈能否在未见样本继续保持对 Expert 的稳定优势，以及还能否提高”。

## 2. 起始差距与逐局分解

旧基线在相同1000局中相对Expert总差额为 `-559`。按结果分层：

|分层|局数|配对差总计|
|---|---:|---:|
|Nonhuman未胡、Expert胡|103|-551|
|两者均未胡且Nonhuman花猪|52|-272|
|两者均未胡且Nonhuman非花猪|527|+10|
|两者均胡|254|+12|
|Nonhuman胡、Expert未胡|63|+270|

结算原因差额主要为自摸 `-277`、花猪 `-304`、点炮 `-66`，被查大叫 `+49` 和杠类约 `+3` 部分抵消。最主要的表现层原因不是“每局都略差”，而是少数路径分叉造成的少胡、少自摸和尾部损失；103个Expert-only胡局贡献了几乎全部净负差。

首处分叉分析中，622局出现策略路径分叉，其中598次首先表现为不同弃牌。高频差异把调查重心从单纯碰杠移到弃牌候选四分量；同时少数杠/弃分叉具有极高单局影响，需单独控制。

## 3. 已完整核查并排除的方向

### 3.1 胡牌强制与满意阈值

F0040/F0041确认 `satisfaction_threshold` 只影响普通候选的满意停止，不得过滤mandatory HU。两组各1000局、s0各57,305次决策中：HU候选317次，mandatory不一致0次，mandatory HU未选择0次。结论：旧差距不是“可胡时因价值阈值放弃胡牌”。

### 3.2 `plan_persistence` 数值

将其从 `.05` 提高到 `.40` 后，计划重启56,248次、重启率98.16%、平均计划年龄0.001、惯性命中57次，候选排序差异0、动作差异0。参数确实接入公式，但重启条件使其几乎无有效作用窗口。结论：单独调高该数值不能修复差距；计划状态机高重启率是架构观察项，不是这批终局差距的已证实主因。

### 3.3 花猪作为参数根因

逐手检查53个花猪局：52局最后一次机会已正确清掉定缺牌，之后末巡重新摸入同门且无新弃牌轮次；仅1局是明确的“最后一张定缺牌选择加杠而非弃牌”错误。花猪会放大尾部结算损失，但绝大多数是固定牌墙末巡机会约束，不是普遍保留定缺牌的参数错误。

### 3.4 `big_hand_preference`

离线 `.80→.60` 会翻转1,614/14,685次弃牌首选，证明它是高影响路径参数；但真实1000局A/B中 `.60` 与 `.80` 的终局指标完全相同，均为171分、358胡、126自摸、41花猪。结论：影响局部排序不等于影响整局收益，它不是剩余111分差距的主因。

### 3.5 固定 `gang_preference=.55` 与杠后代理模型

`.55` 对 `.50` 的10000局合并差为+44，但95% CI `[-.0011,+.0104]`，且seed-a为负，未通过晋级。F0050–F0053的线性EV、公开补牌枚举、两层Expectimax和仅暗杠门禁也均在100/1000/多数据集门禁中失败或方向不稳定。该方向已正式关闭，禁止按已知牌局继续拟合杠后代理系数。

## 4. 真正找到并验证的高影响因素

### 4.1 高杠偏好是“恢复Expert上限”的决定性参数

在弃牌权重先调整为 `.35/.25/.25/.15` 后，旧 `gang_preference=.85` 仍只有171分；仅改为balanced `.50` 后达到282分，与Expert相同：358胡、127自摸、40花猪、214点炮，1000个终局和全部结算指标逐局一致。

路径证据：24局出现首处分叉，其中21局为discard/gang_an、3局为discard/gang_jia；总分提高111。主要恢复来自自摸净收益+98，而不是杠分增加。这证明旧高杠偏好会通过改变后续牌墙路径损害自摸收益。

### 4.2 弃牌权重是“超过Expert”的稳定密集信号

三数据集共30,400个多候选弃牌决策显示：speed差值与终局/胡牌在三组中稳定正向；hand_value差值稳定非正向；defense方向不一致；flexibility正向但很弱。因此只验证最小迁移：

- speed `.35→.40`
- hand_value `.25→.20`
- defense保持`.25`
- flexibility保持`.15`
- gang保持`.50`

F0055真实固定牌局A/B结果：

|数据集|局数|新/Expert基线总分|差值|胡牌变化|自摸变化|花猪变化|
|---|---:|---:|---:|---:|---:|---:|
|主集|1000|359/282|+77|+19|+5|0|
|seed-a|4000|1088/776|+312|+53|+18|-6|
|seed-b|4000|135/-453|+588|+83|+27|-12|
|合并|9000|—|+977|+155|+50|-18|

合并配对均分提升 `+0.10856`，bootstrap 95% CI `[+0.06544,+0.15233]`；三个数据集全部正向，P5和最差1%均未恶化。该结果满足预注册联合门禁，不是只看主1000局后的事后调参。

## 6. 证据质量与已知限制

1. 所有因果晋级均使用固定game_id配对，避免发牌差异；公平性问题已排除。
2. 逐局、逐手audit足以验证动作分叉与参数快照，但早期trace缺少原始shanten/ukeire；F0057已补字段，只增强后续审计，不改变历史策略。
3. 固定牌墙中动作会改变后续摸牌顺序，因此离线候选重排只能筛选参数，不能替代真实 replay；正式结论均以真实A/B为准。
4. 主集、seed-a、seed-b共9000局已提供强于单集的证据，但仍属于有限种子与当前对手阵容（s1–s3 novice_balanced）。
5. 当前“Expert基线”是本项目 `expert_balanced` 策略，不等同于理论最优麻将策略或职业人类上限。
