# Nonhuman 权重反事实

对最终数据中 104 个“expert 胡、nonhuman 未胡”局，在两者首个相同状态弃牌分叉处，使用 nonhuman 已保存的候选特征离线重算权重。

|反事实|翻转到 expert 动作|覆盖配对负差|
|---|---:|---:|
|原 nonhuman 权重|2/104|-110|
|仅 hand_value 0.45→0.25|52/104|-382|
|仅 speed 0.20→0.35|43/104|-247|
|仅 flexibility 0.10→0.15|4/104|-213|
|hand_value+speed|99/104|-560|
|完整 expert 权重|104/104|-579|

结论：主要参数原因已经闭环为 hand_value 过高与 speed 过低的组合；二者解释 99/104 个关键首分叉。flexibility 单独作用小，defense 在两组相同（0.25），不是该差异来源。另一个结构原因是配置中的 `search_depth=8` 目前只被记录，没有进入 evaluator 的前瞻搜索；当前实际决策仍是单步候选特征加权。因此“高搜索深度”没有改善成胡概率，却增加了能力预期误解。

剩余 5/104 个首分叉需要完整 expert 权重中的 flexibility 或候选调整解释；它们不是主要损失。反事实只能证明首分叉排序归因，不能保证换权重后最终必然重现 expert 胡牌，最终仍需固定牌局 A/B 验证。
