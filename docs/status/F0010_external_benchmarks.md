---

## 1. 先说清：任务几乎都不一样

| 任务类型 | 在预测什么 | 典型指标 | 与 F0010 关系 |
|----------|------------|----------|----------------|
| **A. 完整隐藏手牌** | 另三家 13 张牌的 multiset | tile F1 / exact / suit | **F0010 主任务** |
| **B. 出牌动作** | 自己 14 选 1 弃哪张 | discard accuracy % | 极常见，≠手牌 F1 |
| **C. 听口/危险** | 某张是否被听 / 风险 | wait/danger AUC 或 acc | 部分重叠 F0011 |
| **D. 整局实力** | 段位、均顺、点炮率 | rank / R / deal-in | 端到端，含预测+策略 |

公开开源材料里 **几乎没有与 F0010 同构的「隐藏整手 F1」排行榜**。  
多数系统把对手手牌当作 **内部采样/信念**，对外只报 **出牌准确率** 或 **天凤段位**。

因此下文分栏对照，**禁止把 88% 弃牌 acc 直接当成「手牌预测比我们好」**。

## 2. 开源与公开项目（可复现向）

| 项目 | 开源 | 规则 | 公开指标（与预测相关） | 备注 |
|------|------|------|------------------------|------|
| **[Mortal](https://github.com/Equim-chan/Mortal)** | ✅ Rust+DRL | 日麻 | 以 **天凤/雀魂实力、复盘一致率** 为主；作者提醒勿把「与 Mortal 一致率」当唯一牌力 | 无完整手牌 F1 标准榜；对手建模在策略内部 |
| **[mjai-reviewer](https://github.com/Equim-chan/mjai-reviewer)** / Akagi | ✅ 工具链 | 日麻 | 逐巡建议与 AI 一致；危险/听牌数等 HUD 指标 | 评的是 **动作建议**，非 oracle 手牌重合 |
| **[erreurt/MahjongAI](https://github.com/erreurt/MahjongAI)** | ✅ | 日麻 | 文档写 **waiting tiles prediction（LSTM，进行中）** + MLP 危险牌分类；**未给出稳定公开 acc 数字** | 任务更接近 C 类听口/危险 |
| **[MahjongRepository/mahjong](https://github.com/MahjongRepository/mahjong)** | ✅ | 日麻 | 向听/役种在 **2614 万手** 与天凤一致 | **规则引擎准确率**，非对手预测 |
| **RLCard 麻将** | ✅ 环境 | 简化 | 以 RL 回报/胜率评智能体 | 无标准对手手牌 F1 |
| **Botzone 国标赛** | 平台 | 国标 | 比赛胜负 | 学术竞赛常用，非开源模型指标 |

**结论（开源侧）**：可对标的「公开数字」多数是 **B/D 类**；与 F0010 的 A 类 **没有现成同指标 baseline 可下载跑分**。

## 3. 论文/综述中的「预测」类数字

来源侧重：[麻将博弈AI构建方法综述](https://html.rhhz.net/tis/html/202211028.htm)（智能系统学报 2023）及其中引用。

| 来源 | 任务 | 报告指标 | 粗解读 |
|------|------|----------|--------|
| Gao et al. 2018 CNN（天凤） | 弃牌多分类 | **弃牌准确率 68.8%** | 模仿人类弃哪张；非猜对手 13 张 |
| Zheng et al. 2019 监督评估函数 | 弃牌 + 等待相关网络 | **弃牌网络 88.4%**；组合 \(L_i=W\cdot D_i+T_i+R_i\)（等待预测网络 *W*） | 有 **等待/危险** 子网，但文中主打的是弃牌 acc |
| Suphx (Li et al. 2020 arXiv) | 完整日麻智能体 | **天凤段位超 99% 人类**；多模型弃/鸣/立直 | 对手信息经 oracle coach 训练，**不报手牌 F1** |
| Long Cat 系 / KF-TREE | 规则+搜索+对手风险 | 胜率、点炮、Computer Olympiad 名次 | 对手 **风险概率 \(P_{Risk}\)**，非整手 F1 |
| 台大相关学位论文（对手需要牌概率） | 听口需求 | 相对人类 **胡率 25%+** 等对局指标 | 任务 C+D |
| 川麻 DenseNet+XGBoost 等 | 出牌策略 | 「初学者→高级」定性 + 平台对战 | 少见 tile-level 隐藏手牌指标 |
| 国标「预测出牌范围」类硕论 | 潜在出牌集合 | 「范围内更准」叙述 | 接近 **弃牌集合覆盖**，非 multiset F1 |

综述明确指出：**评估标准不统一**——胜率、动作准确率、平台段位混用，**缺少标准学术协议**。

## 4. 与我方 F0010 指标的「量级感」对照

### 4.1 不可直接比，但可建立直觉

| 我方指标 | 数值 (set50) | 外部最接近的类比 | 为何不能等同 |
|----------|--------------|------------------|--------------|
| best tile F1 | **0.51** | 无公开同任务榜 | 组合空间 \(\sim C\) 巨大；随机基线已 ~0.37 |
| Top1 F1 | **0.44** | — | UI 只展示 #1 时的体感 |
| lift vs random | **+0.14** | 比「相对随机」更有意义 | 多数论文不报 random baseline F1 |
| rank1=best | **46%** | 有点像「排序是否找对最佳假设」 | ≠ 弃牌 acc |
| 向听 MAE | **~2.1** | 外部几乎不报 pred-shanten vs true | 我方独特诊断指标 |
| late best | **0.52** | 信息增多后应上升 | 符合不完全信息常识 |

### 4.2 与「弃牌准确率 70–88%」怎么比？

- 弃牌：从 **可见自己 14 张** 中选 1，类空间 ≤14，人类日志可监督，**acc 70%+ 很常见**。  
- F0010：从 **remain 与联合约束** 中还原 **13 张隐藏牌**，类空间天文量级；exact_set≈0 是预期。  
- **随机弃牌基线 ~25–40% 量级（视规则）**；随机手牌 F1 我方测得 **~0.37**。  
- 故：F0010 best **0.51 ≈ 随机+14pt**，是 **弱信号任务上的实质增益**；不能拿去和 88% 弃牌 acc 比高低。

### 4.3 与顶级开源日麻（Mortal）怎么比？

| 维度 | Mortal 等 | F0010 |
|------|-----------|--------|
| 目标 | 打出接近专家/自博弈的 **动作** | 估计对手 **手牌形** 供 UI/F0011 |
| 训练 | 百万级牌谱 + RL | 规则+启发式+固定集复现 |
| 强度指标 | 平台段位/均顺 | 无 |
| 可解释性 | 低（黑盒） | 高（规则清单可调） |
| 川麻血战 | 非原生 | **原生** |

二者 **互补**：Mortal 不做你的产品规格；你也不应用 Mortal 段位评价 F0010 F1。

## 5. 可借鉴、可落地的「对比协议」建议

若要与外部世界 **可对齐**，建议增补（不必立刻实现）：

| 协议 | 指标 | 用途 |
|------|------|------|
| **C′ 听口** | 对 true 听牌者：预测 ukeire 的 precision/recall / top-k 命中 | 对齐 Zheng 等「等待预测」与 F0011 危险 |
| **危险排序** | 真·放炮事件上：危险等级 AUC / 放炮率↓ | 对齐 Mortal/Akagi 防守价值 |
| **主色/定缺** | suit match、定缺一致率 | 川麻特有，外部很少报 |
| **动作模仿**（可选） | 若有人类/AI 牌谱：弃牌 top-1 acc | 与 68–88% 文献同形 |
| **固定 set 公开** | 继续 20⊂50⊂100 | 你们已有，优于多数论文不可复现 |

## 6. 综合判断（给产品/研发）

1. **公开开源里找不到「完整对手手牌 F1」的成熟标杆**；你们的指标设计反而更细、更可诊断。  
2. **0.51 best / +0.14 lift** 在「还原整手隐藏牌」这一极难题上是 **合理的第一代水平**；不必因看到 88% 弃牌 acc 而否定。  
3. 外部强 AI 的优势在 **端到端打牌与听口/危险**，不在公布手牌 F1——若要对标，应做 **P1 听口 + F0011 放炮**，而非只卷 tile F1。  
4. 文献共识：**评估不统一、对手建模薄弱**——你们已有 joint remain + 规则清单，方向对；缺的是 **策略出牌分布下的外部效度** 与 **听口级指标**。
