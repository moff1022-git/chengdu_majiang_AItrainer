# F0054 三数据集弃牌特征筛选结果

日期：2026-08-04

## 数据

主集、seed-a、seed-b各1000局旧`.50`完整audit，共提取30,400个s0多候选弃牌决策。三组分别为10,026、10,223、10,151条。

## 审计缺口

候选trace的features只有speed、hand_value、defense、flexibility，没有原始shanten或ukeire。代码确认ukeire仅在shanten=0时由引擎返回，再压缩进入speed；因此现有trace不能直接审计1向听以上的有效进张。该缺口需另立功能补充，不能从终局反推。

## 稳定性筛选

比较被选弃牌与候选第二名的特征差，并以所在牌局终局分数/是否胡作事后分层：

|特征|主集rho|seed-a rho|seed-b rho|方向|
|---|---:|---:|---:|---|
|speed delta|0.0632|0.0502|0.0532|三组稳定正向|
|hand_value delta|-0.0066|-0.0219|-0.0070|三组非正向|
|defense delta|0.0046|0.0076|-0.0039|方向不一致|
|flexibility delta|0.0219|0.0036|0.0109|正向但很弱|

三个数据集中，胡牌局的speed delta均高于未胡局；hand_value delta均是胡牌局更低。该结果与F0043“speed不足、hand_value过高”的方向一致，但当前基线已经是F0043的`.35/.25/.25/.15`，所以只允许验证一个很小的继续迁移，不得大幅调权。

## 决策

通过方向筛选的最小候选为speed `.35→.40`、hand_value `.25→.20`，defense/flexibility保持`.25/.15`。观察相关不等于因果；必须通过F0055固定100/1000及三数据集A/B，且联合门禁全部满足才可晋级。
