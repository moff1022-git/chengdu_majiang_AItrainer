## 4. 矛盾与设计债（讨论用）

1. **L2 向听表贴近真值均值，但预测手牌结构仍远** → 目标对了、候选分布不对；应改 **生成/过滤**，不是再改 target。  
2. **L3 信分数 vs 分数本身偏** → rank1=best↑ 而 Top1 F1 不↑：best 常在 #2–#5，重排不够。  
3. **M2 斩色 K 调高减假阳性后信号更稀** → 与「主色 60%」目标冲突。  
4. **F0011 危险更严 ≠ 更少放炮** → 需对局验证，否则顾问会过度防守伤进攻。  
5. **inventory 与代码漂移** → 讨论前应先对齐文档，避免按旧表决策。
