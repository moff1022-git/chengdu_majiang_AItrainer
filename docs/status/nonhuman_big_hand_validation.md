# big_hand_preference 验证

已按 F0045 对现有完整 audit 做离线反事实，保持 F0043 四项权重不变。

已知结果：将 `big_hand_preference` 从 0.80 降至 0.60 会改变 1,614/14,685 次弃牌首选（11.0%）；降至 0.40 会改变 3,119 次（21.2%）。翻转主要发生在计划重启和候选分差较小的弃牌阶段，说明该参数确实是高影响路径参数。

但现有 audit 只能重排当前候选，不能模拟重排后的后续牌局，因此尚未证明 0.60 或 0.40 能提高总分、减少花猪或超过 expert。下一步应只验证最有希望的 0.60（必要时再验证 0.40）固定牌局 A/B，不应直接修改正式预设。
