# 进度状态（跨机同步基线）

按 [`../DEVELOPMENT.md`](../DEVELOPMENT.md) **§2.1 + §2.2** 与根目录 [`../../AGENTS.md`](../../AGENTS.md) 规则 7：

- 每轮结束：对话内「已完成 + 下一步清单」**且**  
- **强制**把可恢复基线写入本目录（不以 chat session 为跨电脑状态源）。

## 文件

| 文件 | 用途 | 是否强制 |
|------|------|----------|
| **`LATEST.md`** | 始终**覆盖写**为最近一轮收尾 + 当前主线 / 下一步队列 | **强制 · 每轮** |
| **`DOC_CODE_BASELINE.md`** | 文档↔程序一致性对照（版本/F 状态/易错点） | 发布或大审计后更新 |
| `YYYY-MM-DD.md` 或带时间戳 | 日终/长文历史 | 可选 |
| 专题 `F0010_*.md` 等 | 评估报告、诊断切片 | 按任务 |

## 换机 / 新 session 读序

1. 读 `LATEST.md`  
2. 读 `../changelog.md` 最近条目  
3. 读任务相关 `../features/` 或 `../milestones/`  

无 `LATEST.md` 视为流程违规；应先补写再开发。

## `LATEST.md` 建议结构

```markdown
# 进度快照
> 日期 — 一句话标题

## 本轮摘要
## 功能线状态（表）
## 评估锚点 / 风险
## 下一步队列（立即 + 后续）
```
