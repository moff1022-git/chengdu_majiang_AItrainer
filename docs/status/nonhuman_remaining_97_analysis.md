# Nonhuman 权重修正后剩余 97 分分析

权重 A/B 与 expert 均胡 358 局、HU 事件数相同。结算净收益差：自摸 -92、花猪 -32、点炮 -9、查大叫 +4、杠类合计 +32，合计 -97。

动作数量也几乎相同：pong 完全相同 1422；discard 仅少 1；明杠少 1、加杠多 4、暗杠多 3。因此碰杠“次数”不是剩余差额主因，主要是同样胡牌次数下的胡牌方式/价值不同：weight A/B 的自摸净收益 140，expert 232。

额外花猪只有一局 `...-000692`，差 -23。两组在末巡都先清空定缺，之后在牌墙剩 2 时重新摸入 1 张定缺并立即弃出；权重组仍被结算标记花猪而 expert 没有，需单独核对 settle_tags 与最终状态，可能是路径中的终局状态/结算边界，而不是最终弃牌选择。

剩余原因排序：

1. 自摸价值差（-92）是 97 分的主体；
2. 单局花猪结算差（-32）是尾部放大器；
3. 点炮和查大叫差异较小；
4. 碰杠净收益反而比 expert 高约 32，排除为剩余负差直接原因；
5. profile 风格参数主要通过极少量杠动作和路径改变胡牌价值，而非胡牌数量。

推荐参数：保留 nonhuman 的计算/候选配置，将决策权重正式调整为 0.35/0.25/0.25/0.15。碰杠偏好暂不调整；需先解决 search_depth 未用于真实前瞻及花猪结算边界，再评价是否能超过 expert。
