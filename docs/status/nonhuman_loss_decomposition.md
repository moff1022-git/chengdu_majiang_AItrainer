# Nonhuman 低分原因分解

同一 1000 固定牌局对 expert，s0 总差额 -559。

按胡牌结果分层：

|分层|局数|配对差总计|
|---|---:|---:|
|nonhuman 未胡、expert 胡|103|-551|
|两者均未胡且 nonhuman 花猪|52|-272|
|两者均未胡、nonhuman 非花猪|527|+10|
|两者均胡|254|+12|
|nonhuman 胡、expert 未胡|63|+270|
|nonhuman 未胡、expert 胡且花猪|1|-28|

负差主要由 103 个“expert 胡而 nonhuman 未胡”局产生；非花猪且两者都未胡的 527 局基本持平。花猪带来明显尾部损失，但前述因果分析显示 52/53 是末巡机会约束，而不是策略保留定缺牌。

按结算原因分解净收益：nonhuman 相对 expert 的主要差额为自摸 `-277`、花猪 `-304`、点炮 `-66`；部分被查大叫 `+49`、明/暗/加杠合计约 `+3` 抵消。说明高碰杠没有产生足够净收益，核心是自摸能力下降和花猪高损失尾部。

已确认原因层级：

1. 主要表现原因：少胡 41 局，尤其少自摸，103 个 expert-only 胡局贡献 -551；
2. 主要参数/模型候选：hand_value 高权重与 speed/flexibility 低权重造成首处分叉弃牌，622 局首处分叉中 598 次为不同弃牌；
3. 次要原因：过度碰杠改变路径，但其净杠收益并未恶化，balanced claims A/B 只改善 40 分，故不是主因；
4. 尾部放大器：花猪结算差 -304，但多数是末巡机会约束；仅 1 局为明确加杠定缺牌错误；
5. 已排除：HU mandatory、satisfaction threshold、发牌不公平、plan_persistence 数值本身。

仍需进一步完成的因果闭环：对 103 个 expert-only 胡局按首分叉候选特征做离线反事实重排，量化 hand_value/speed/flexibility 每项能恢复多少胡局，才能把“候选参数”提升为最终根因。
