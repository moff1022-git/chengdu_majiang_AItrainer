# Nonhuman 其他方向分析（任务 1–7）

已对权重 A/B 与 expert 的最终 trace 做离线检查，未启动新 1000 局。

- 权重 A/B s0：总分 185、胡牌 358、花猪 41；expert：282、358、40。
- 两者胡牌数量和番数分布基本一致，剩余差异来自自摸/付款路径，而非少胡。
- 权重 A/B s0 决策 57,305 次，其中计划重启 54,934 次，重启率 95.86%；非重启 1,058 次。计划重启过密仍是结构性问题。
- 弃牌候选最高/次高分平均差约 0.024，说明大量决策接近，防守和牌值的细微特征会改变路径。
- `big_hand_preference`、防守安全度与自摸路径相关，但现有 trace 不含完整对手威胁反事实，尚不能证明单一风格参数能超过 expert。
- `plan_persistence` 仍不是当前可行优化方向：重启率过高使其有效窗口极小。

本轮结论：当前最有证据的非杠方向是“计划重启条件过敏 + 近等候选下的防守/自摸路径差异”，但尚未得到超过 expert 的参数候选；不应直接修改正式配置或重跑 1000 局。
