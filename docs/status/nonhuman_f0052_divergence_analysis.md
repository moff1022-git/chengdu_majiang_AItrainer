# F0052 终局分叉逐手分析

## 样本与方法

逐game_id对齐F0052与旧 `.50` 的1000份 `games.jsonl` 和完整audit，筛出s0终局分数不同的28局，比较s0逐次公开PlayerView、合法动作、候选得分和首次不同动作。总配对差为 `-48`。

## 首分叉分类

- 16局首次分叉直接发生在明杠候选：旧 `.50` 选择明杠，F0052大多改为碰。
- 2局首次分叉涉及暗杠：`000453`从暗杠改为弃牌，终局 `+18`；`000943`从弃牌改为暗杠，终局 `-2`，合计 `+16`。
- 其余10局为前序杠分叉引起的后续路径传播，首次可对齐决策已不再处于同一状态，不能把后续弃牌差异当作独立因果。

## 负向尾部

最大损失局 `fairness-20260802-fair-004-000169`：

- 公开决策时为第1巡，明杠 `tong_1` 与碰均合法。
- 旧 `.50` 明杠得分 `0.72335775`，碰 `0.71935775`，选择明杠。
- F0052明杠调整后 `0.71616073`，低于碰，选择碰。
- 旧路径s0随后5番自摸；F0052路径s0未胡，终局差 `-93`。

F0052对明杠的补牌期望惩罚只有千分级差异，却足以跨过旧模型刻意设置的 `0.004` 明杠—碰间隔。固定牌墙下，补牌会改变整局后续摸牌顺序；公开概率只能估计局部手牌质量，无法用单次期望安全预测整局顺序效应。该不确定性使明杠抑制出现低频、极高损失尾部。

## 可分性结论

正负明杠样本在公开的speed、hand_value、flexibility、wall_remaining上明显重叠，不能从当前28局建立无泄漏且可靠的连续阈值。杠类型是可稳定、规则内、无需未来信息的离散特征：

- 明杠直接与碰竞争，F0052的小调整会系统性翻转旧 `.50` 的窄分差；不适合接入两层代理。
- 暗杠与弃牌竞争，F0052两处分叉在本数据集净 `+16`，值得单独验证。
- 加杠在本轮没有足够独立分叉证据，应保持旧机制。
