# Nonhuman 花猪因果分析

基于最终 baseline 1000 局完整 audit，对 s0 的 53 个花猪局逐手检查。

- 53 局终局均只剩 1 张定缺牌；
- 53 局都曾有合法弃出该定缺牌的最后机会；
- 其中 52 局在最后一次弃牌机会中正确弃出定缺牌，但随后又摸入同门牌，牌墙结束前没有新的弃牌轮次；
- 最后机会时牌墙中位数仅 4 张，31/53 局牌墙不超过 4 张；
- 仅 1 局存在明确策略错误：`...-000835` 在剩余 9 张时，对最后一张 `tiao_8` 选择 `gang_jia` 而非 discard。杠候选 0.72426984，弃牌候选 0.70292857，差 0.02134127；主计划已经是 `clear_dingque`，说明 evaluator 没有禁止用最后一张定缺牌加杠。

结论：53 个花猪中，52 个主要是末巡重新摸入定缺牌造成的机会约束，不是参数权重或定缺候选遗漏；只有 1 个可归因于动作评价/规则优先级缺陷。花猪不是 nonhuman 总体低分的主要参数根因。
