## 0. 结论速览（开发 C1 时怎么选）

| 优先级 | 平台 | Mac 上怎么跑 | 适合作采集训练源？ |
|--------|------|--------------|-------------------|
| **P0** | **腾讯欢乐麻将** | App Store **原生支持 iPhone/iPad/Mac** | **首选**：本机可装、可录屏，与已有标注图库一致 |
| **P0** | **本项目 GUI** | 原生 Python / 已打包 `.app` | **算法台架**（非外站，但开发管线必备） |
| **P1** | **JJ 麻将** | App Store 列 **Mac（需 Apple 芯片 M1+，macOS 11+）**；部分说明写「未针对 macOS 验证」 | 可试装；若黑屏/崩溃再退而求其次 |
| **P1** | **人人麻将** | App Store 列 **Mac（M1+，macOS 11+）**；「专为 iPad 设计 / 未针对 macOS 验证」 | 可试装；布局可能随 iPad 缩放 |
| **P1** | **微信小游戏 · 四川麻将血战到底** | **Mac 版微信**内打开小游戏（能力随微信版本变化） | **强烈建议**：与「线上产品」一致；比猜渠道壳更准 |
| **P2** | **指尖四川麻将（禅游）** | 有 iOS App；是否上架 Mac 以 Store 当时「兼容性」为准 | 真机 iPhone 投屏/录屏 更稳 |
| **P2** | **小书童 / 指尖等渠道壳** | 多为 **iOS/Android 专供** | Mac 上通常需 **模拟器/云手机**（不推荐作首发标定） |
| **—** | **实体桌实拍视频** | 不涉及「运行」 | 可训练检测，但 **ROI 与 App 不同**，勿当主 profile |

> 你当前若是 **Apple Silicon Mac Studio**：优先试 **欢乐麻将（Mac App Store）** + **Mac 微信小游戏**；两者都不需要安卓模拟器。

## 1. 分产品说明

### 1.1 腾讯 · 欢乐麻将全集

| 项 | 内容 |
|----|------|
| Mac 原生 | **是**。App Store 页面列出 **iPhone、iPad、Mac**；macOS 要求公开资料为 **10.10+**（以商店页为准） |
| 入口 | Mac App Store 搜「欢乐麻将」/ [id689180123](https://apps.apple.com/cn/app/欢乐麻将/id689180123) |
| 四川玩法 | 合集内含四川血流/血战等（以游戏内房间为准） |
| 采集注意 | 3D 侧家河难；Mac 窗口分辨率固定后适合做 Layout Profile |
| 与视频图库 | 已有 `frames/annotated/huanle/` 真实标注帧 |

**判定：Mac 可运行（官方 App Store 路径）。**

---

### 1.2 竞技世界 · JJ 麻将

| 项 | 内容 |
|----|------|
| Mac 原生 | App Store 兼容性写明 **Mac：macOS 11+ 且 Apple M1 或更新**；同时有「**Designed for iPad / Not verified for macOS**」类说明 |
| 入口 | Mac App Store / iPad 应用在 Apple 芯片 Mac 上运行 |
| 注意 | 「未验证」= 可能能开但体验/崩溃风险自担；Intel Mac 通常 **不能**跑 iPad 转 Mac 应用 |
| 另 | 另有微信小游戏形态 JJ（依赖微信） |

**判定：Apple 芯片 Mac 可尝试官方路径；Intel 不保证。**

---

### 1.3 人人麻将

| 项 | 内容 |
|----|------|
| Mac 原生 | App Store 列 **Mac：macOS 11+、M1+**；文案有「专为 iPad 设计，未针对 macOS 验证」 |
| 入口 | [id6448985846](https://apps.apple.com/cn/app/人人麻将-欢乐休闲棋牌游戏/id6448985846) |

**判定：Apple 芯片 Mac 可尝试；需自测登录与川麻房间。**

---

### 1.4 微信小游戏 · 四川麻将血战到底（禅游等）

| 项 | 内容 |
|----|------|
| 手机 | 微信 → 搜小游戏「四川麻将血战到底」 |
| Mac | 安装 **[微信 for Mac](https://mac.weixin.qq.com/)** → 登录 → 小游戏中心 / 聊天里打开同一小游戏 |
| 能力 | 微信桌面版对小游戏支持**随版本迭代**；部分小游戏仅手机可用或功能裁剪——**以当前微信版本实测为准** |
| 应用宝 | 部分页面写「电脑版支持小游戏」（偏 Windows 应用宝电脑版）；Mac 仍以 **Mac 微信** 为主路径 |
| 采集注意 | 窗口含微信标题栏/胶囊区；需单独 Layout Profile |

**判定：优先路径为 Mac 微信；能否玩「该」小游戏必须本机点开验证（不能 100% 保证所有小游戏桌面可用）。**

---

### 1.5 禅游 · 指尖四川麻将 / 渠道「熊猫」川麻

| 项 | 内容 |
|----|------|
| 指尖四川麻将 | App Store 有 iOS 版（禅游）；是否显示 **Mac 兼容** 以商店「信息」栏为准（常为 iPhone/iPad 为主） |
| 熊猫单机/血战渠道包 | 调研视频中竖屏单机场偏 **手机 App**；Mac 上常见路径：iPhone 镜像 / 未官方 Mac 包 |
| 小米等 Android 包 | **不能**在 Mac 上原生安装；需模拟器（性能与输入复杂，**不建议**做 C1 首发） |

**判定：Mac 原生不确定 → 默认按「手机 App + 投屏/镜像」规划；不要默认能装 Mac 客户端。**

---

### 1.6 小书童等其它渠道壳

| 项 | 内容 |
|----|------|
| 典型分发 | iOS / Android |
| Mac | 无统一 Mac 客户端；模拟器成本高 |

**判定：Mac 上不优先。**

---

### 1.7 仅用「线上视频」、不在 Mac 上跑游戏？

若训练数据**只**来自公开视频抽帧（不实时采集本机窗口）：

- **不依赖**游戏能否在 Mac 运行；任意平台视频均可。  
- 但 **UI 版本 / 分辨率 / 录屏边框** 与真机不一致，模型迁移会差。  
- 推荐组合：**视频冷启动 + Mac 可跑客户端热校准**。

## 2. 推荐组合（你的目标：视频训练 + 开发采集程序）

```text
阶段 A（开发算法）
  └─ 本项目 .app / python GUI 合成帧 + 已有 huanle 标注视频帧

阶段 B（Mac 本机闭环）
  ├─ 安装「欢乐麻将」Mac 版 → 固定窗口尺寸 → 录屏/截帧
  └─ 安装「微信 for Mac」→ 打开四川麻将血战到底小游戏 → 录屏（若可用）

阶段 C（扩展）
  └─ JJ / 人人（M1+ 试装）或 iPhone 接 Mac 镜像录屏
```

### 2.1 本机建议检查清单（5 分钟）

在 Mac Studio 上按顺序点：

1. App Store 搜 **欢乐麻将** → 看是否显示「在这台 Mac 上获取」  
2. App Store 搜 **JJ麻将** / **人人麻将** → 看兼容性是否含 Mac（M1+）  
3. 打开 **微信 Mac** → 搜小游戏「四川麻将血战到底」→ 能否进入房间  
4. 记一笔：分辨率、横竖屏、是否有刘海/刘海安全区  

把结果回填到本文件「实测记录」即可。
