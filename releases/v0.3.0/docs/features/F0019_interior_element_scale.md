# F0019 — 窗内元素等比缩放（1080p 基准）

| 字段 | 值 |
|------|-----|
| **编号** | F0019 |
| **标题** | Interior element uniform scale from 1080p baseline |
| **状态** | **`Done`**（已实现；用户：先文档后直接实现） |
| **类型** | UI 适配 / 布局不变、元素缩放 |
| **依赖** | F0018（外框与内部分区已落地）；UI_DESIGN_STANDARD §8 |
| **关联** | `display/interior_scale.py`、`layout.py`、`main_interior.py`、`table_view.py`、`control_panel.py`、`players/seat_window.py`、`players/view/responsive.py` |
| **不改** | 多窗外框 A/B/C 落位比例；MAIN 80/20、座位 67/33 等**分区比例** |

---

## 1. 目标

1. **布局结构不变**：外框 plan、内部分区百分比与条带顺序维持 F0015–F0018。  
2. **以 1080p 默认客户区为基准与最小窗**：  
   - MAIN / 人类 Full：**885×498**  
   - AI Full：**442×249**  
3. **基准窗内完整显示**：在 S=1（客户区=基准）时，通过**适配后的元素基准尺寸**保证各区内容可完整落入（可滚动的日志/弃牌区在预算内显示，关键手牌/操作不依赖外层滚动才能看到）。  
4. **等比缩放**：客户区变大（用户拉大窗或更高分辨率 plan）时  
   `S = min(Cw/Cw0, Ch/Ch0)`，**所有元素尺寸 × S**（牌宽高、字号、间距、行高、按钮高）。  
5. **客户区小于基准**（异常/旧 plan）：`S < 1`，继续缩小元素以尽量完整显示；应用层应尽量把 **minsize 锁在基准**。

---

## 2. 缩放公式（权威）

```text
# 基准客户区（1080p 默认完整模式，UI_DESIGN_STANDARD §8.2）
MAIN_REF  = (885, 498)
HUMAN_REF = (885, 498)
AI_REF    = (442, 249)

S = min(Cw / Cw0, Ch / Ch0)     # S > 0
size_px = max(size_floor, round(size_base * S))
```

| 窗角色 | Cw0×Ch0 | 典型来源 |
|--------|---------|----------|
| main | 885×498 | pygame 主窗客户区 |
| play（人类） | 885×498 | Tk 座位窗 |
| watch（AI） | 442×249 | Tk 座位窗 |

**分区比例不乘 S**（仍 80/20、67/33、条带 1+2 行语义）；**仅像素度量乘 S**。

---

## 3. 基准元素尺寸（S=1 时）

在 1080p 基准窗内保证「完整显示」的 **base**（实现常量，可微调 ±2px）：

### 3.1 主窗 MAIN

| 元素 | base（S=1） | floor |
|------|-------------|-------|
| 桌面统一 `tile_w` | **28** | 12 |
| `tile_h` | `round(tile_w * 1.4)` | — |
| 侧栏标题字号 | 15 | 9 |
| 侧栏正文字号 | 12 | 8 |
| 控制行高 | 24 | 16 |
| 间距 pad | 6 | 2 |

> 相对原 F0007 的 36–52 牌宽偏大：在 885×498 四扇区+DICE 下易挤爆；F0019 将 S=1 基准下调以保证装下，窗变大后再放大。

### 3.2 座位窗 play / watch

| 元素 | play base | AI base | floor |
|------|-----------|---------|-------|
| 手牌 `tw` | 28 | 18 | 10 |
| 弃牌 `tw` | 22 | 14 | 8 |
| 正文字号 | 11 | 9 | 7 |
| 标题字号 | 14 | 11 | 8 |
| 操作条高度预算 | 56 | 40 | 28 |
| 内边距 | 4–8 | 2–4 | 1 |

手牌网格：在 **OP_PLAY 可用宽高** 内用 `compute_tile_grid`，`min_tw/max_tw` 均随 S 缩放；**允许低于旧 F0006 的 36px 下限**（本功能明确要求缩小以装下）。

## 4. 行为细则

| # | 规则 |
|---|------|
| R1 | **不改** pack/place 分区比例与条带顺序 |
| R2 | 字体、牌面 PhotoImage、gap、按钮 padx/pady、SIDE 行高均随 S |
| R3 | 主窗 `Layout.from_window`：`tile_w = clamp(round(28*S), 12, 96)`；取消「永不低于 36」对小 S 的硬顶（大 S 可超过原 MAX 52） |
| R4 | 座位窗 resize → 重算 S → 更新 font + 触发手牌/弃牌重绘 |
| R5 | **外框尺寸**：完整模式 = plan 尺寸且 **≤1080p 完整表**（MAIN/人类 885×498、AI 442×249）；**禁止默认放大**；完整模式 min=max 锁定；精简可缩小 |
| R6 | 资源仍仅 `assets/`；缩放用现有 smoothscale / PhotoImage |
| R7 | 不改引擎规则与合法动作 |
