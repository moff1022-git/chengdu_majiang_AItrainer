## 1. 目标与范围

### 1.1 目标

规定 AI 观战窗内：

1. 与人类窗对齐的 **左右 67/33** 与折叠行为  
2. **左侧 AI 操作区**（实为只读操作信息区）纵向分区  
3. **右侧扩展区**：AI 操作日志 + 本家弃牌  
4. 与人类窗的 **差异点**（无吃碰杠胡操作条；扩展区上为日志而非对手 HUD）

### 1.2 In Scope / Out of Scope

| In Scope | Out of Scope |
|----------|--------------|
| watch 客户区几何与区域命名 | 引擎 AI 决策逻辑 |
| 折叠扩展区 | 人类 play 窗（见 HUMAN_WINDOW_LAYOUT） |
| 完整模式默认展开扩展区 | 本轮不写业务代码、不出图（另令） |

## 2. 总体：左右结构（与人类窗同构）

客户区宽 `Cw`、高 `Ch`。

```text
┌─────────────────────────────────┬──────────────────┐
│                                 │                  │
│     AI 操作区 OP                │  扩展显示区 EXT  │
│           67%                   │   33%（可折叠）  │
│                                 │                  │
└─────────────────────────────────┴──────────────────┘
```

| 区域 ID | 名称 | 默认宽度占比 | 高度 | 可折叠 |
|---------|------|--------------|------|--------|
| **OP** | AI 操作区（只读主区） | **67%** | 100%·Ch | 否 |
| **EXT** | 扩展显示区 | **33%** | 100%·Ch | **是 → 向左收起隐藏** |

```text
# 展开态
Ow = floor(Cw * 0.67)
Ew = Cw - Ow
Ox, Oy = 0, 0
Ex, Ey = Ow, 0
Oh = Eh = Ch

# 折叠态
Ow_collapsed = Cw
Ew_collapsed = 0
EXT 不绘制
```

### 2.1 折叠交互

| 项 | 规格 |
|----|------|
| 方向 | 扩展区 **向左** 收起 |
| 触发 | 「扩展 › / ‹」按钮；可选快捷键 |
| 默认 | **展开** |
| 折叠后 | OP 占满宽；纵向占比不变 |

与人类窗 **同一折叠交互范式**，便于多窗一致体验。

## 3. OP — AI 操作区（左 67%）

矩形：`(0, 0, Ow, Ch)`。自上而下四段（与人类窗 **同序同比例**，手牌段无操作条）：

```text
┌─────────────────────────────────────┐
│ OP_INFO     玩家信息          1 行  │
├─────────────────────────────────────┤
│ OP_STATUS   当前状态          20%   │  左右平分
├─────────────────────────────────────┤
│ OP_PLAY     实时手牌          60%   │  上副露 / 下手牌（无操作条）
├─────────────────────────────────────┤
│ OP_SETTINGS 状态设置          2 行  │
└─────────────────────────────────────┘
```

### 3.1 高度分配

与 [`HUMAN_WINDOW_LAYOUT.md`](HUMAN_WINDOW_LAYOUT.md) §3.1 **相同**（**2026-07-21**：20% / 60%）：

```text
H_ROW ≈ clamp(round(Ch * 0.04), 28, 40)
H_info = H_ROW
H_set  = 2 * H_ROW
rest   = Ch - H_info - H_set
H_status = floor(rest * 0.20 / 0.80)   # 权重 20
H_play   = rest - H_status             # 权重 60
```

验收：**状态区 : 手牌区 ≈ 20 : 60**（相对 flex）。

### 3.2 OP_INFO — 玩家信息（1 行）

| 元素 | 说明 |
|------|------|
| 座位号 | 如 `S2` |
| 角色 | **AI 观战** / 策略名摘要 |
| 定缺色标 | 有则显示 |
| 只读徽标 | 可选「只读」 |
| 折叠入口 | 扩展区折叠钮 |

### 3.3 OP_STATUS — 当前状态（20% 高 · 左右严格 50%/50%）

与人类窗相同：左半当前打出（牌框高 = 状态区高 × **95%**，宽高比 **1:1.4**）；右半局分。

与人类窗 **同一结构**：

```text
┌──────────────────┬──────────────────┐
│ STATUS_L  50%    │ STATUS_R  50%    │
└──────────────────┴──────────────────┘
```

| 子区 | 内容 |
|------|------|
| **STATUS_L** | 当前打出 **实时牌面**；**谁打出**；**牌墙剩余** |
| **STATUS_R** | **当前局数**；**当前得分**（本座分；可选四家缩略） |

### 3.4 OP_PLAY — 实时手牌区（60% 高）

```text
┌─────────────────────────────────────┐
│ PLAY_MELDS   副露区          ~35%   │  占 OP_PLAY 内
├─────────────────────────────────────┤
│ PLAY_HAND    手牌区          ~65%   │  只读 · 无操作条
└─────────────────────────────────────┘
```

| 子区 | 内容 |
|------|------|
| **PLAY_MELDS** | 本座副露（碰/杠组），只读 |
| **PLAY_HAND** | 本座手牌（观战可见该 AI 手牌），**只读** |

#### 与人类窗差异（强制）

| 项 | 人类 play | **AI watch（本文）** |
|----|-----------|----------------------|
| 手牌点击/双击出牌 | 有 | **无** |
| 碰/杠/胡/过操作条 | 有 | **无** |
| 换三张/定缺点选 | 有 | **无**（仅展示结果变化） |
| 光标 | hand2 | arrow / 默认 |

手牌区纵向空间全部给副露+手牌，**不预留操作条高度**（可将人类窗操作条所占高度并入手牌展示）。

牌面：只读 Label；可缩放换行（F0006）。

### 3.5 OP_SETTINGS — 状态设置（2 行）

| 行 | 内容示例 |
|----|----------|
| 第 1 行 | **自动开始** 开/关；**对手牌预测** 开/关 |
| 第 2 行 | **出牌推荐** 相关开/关（若 watch 座无推荐展示则控件可禁用并灰显，**仍占位**以保持与人类窗行结构一致）；**AI 策略** 选择（规则/随机/当前S2 等，下局生效） |

- 两行固定；与人类窗设置区 **同行数同骨架**  
- watch 特有：策略切换（F0014 A7）优先放在第 2 行

## 4. EXT — 扩展显示区（右 33%，可折叠）

```text
┌─────────────────────┐
│ EXT_LOG    30%      │  AI 操作日志
│                     │
├─────────────────────┤
│ EXT_DISC   70%      │  本家弃牌
│                     │
└─────────────────────┘
```

```text
H_log  = floor(Ch * 0.30)
H_disc = Ch - H_log

EXT_LOG:  y = 0,      h = H_log
EXT_DISC: y = H_log,  h = H_disc
```

### 4.1 EXT_LOG — AI 操作日志（上 30%）

| 元素 | 说明 |
|------|------|
| 日志流 | 本座 AI 相关事件：摸/打/碰/杠/胡/过/定缺/换三张等 |
| 格式 | `[巡] 动作 牌面…` 或带时间戳 |
| 范围 | **优先本座**；可选「全部/本座」过滤（实现阶段） |
| 滚动 | 新事件贴底；区内滚动 |
| 容量 | 环形缓冲（如 200 条） |

**与人类窗差异**：人类 EXT 上区为 **对手状态 HUD**；AI 窗上区为 **AI 操作日志**（非对手表）。

### 4.2 EXT_DISC — 本家弃牌（下 70%）

| 元素 | 说明 |
|------|------|
| 本座弃牌网格 | 与人类窗 EXT_DISC 同职责 |
| 空态 | 「暂无弃牌」 |

折叠 EXT 时弃牌以主桌为准。

## 5. 与人类窗对照总表

| 区域 | 人类 play | AI watch |
|------|-----------|----------|
| 左右 67/33 + 折叠 | 同 | **同** |
| OP_INFO 1 行 | 人类标签 | AI/策略/只读标签 |
| OP_STATUS 20% 左右分 | 同 | **同** |
| OP_PLAY 60% 副露+手 | 有操作条 | **无操作条，只读手牌** |
| OP_SETTINGS 2 行 | 自动开始/预测/推荐 | 同骨架 + **策略**；推荐可灰显 |
| EXT 上 30% | 对手 HUD | **AI 操作日志** |
| EXT 下 70% | 本家弃牌 | **同：本家弃牌** |

---

## 6. 绘制层级（建议）

```text
1. OP 背景
2. INFO → STATUS → PLAY（副露→只读手牌）→ SETTINGS
3. EXT（若展开）：LOG → DISC
4. 折叠按钮
5. 只读遮罩/提示（可选，勿挡日志）
```
