## 1. 目标与范围

1. **左右分栏**比例与职责  
2. **实时牌局区** 几何划分（掷骰子中心 + 四角连线四分）  
3. **右侧信息/设置区** 上中下分区  
4. 四名玩家在牌局区内的方位（下/右/上/左）

- 区域宽高占比与坐标算法（逻辑像素）

- 本轮不写业务代码、不出图（出图另令）

## 2. 总体：左右模式

主窗客户区宽 `Cw`、高 `Ch`（不含系统标题栏）。

```text
┌────────────────────────────────┬──────────────────┐
│                                │                  │
│     实时牌局显示区 TABLE       │   侧栏 SIDE      │
│           80%                  │     20%          │
│                                │                  │
└────────────────────────────────┴──────────────────┘
         宽 0.80·Cw                      宽 0.20·Cw
```

| 区域 ID | 名称 | 宽度占比 | 高度 | 职责 |
|---------|------|----------|------|------|
| **TABLE** | 实时牌局显示区 | **80%** | 100%·Ch | 牌局、骰子、四家手牌/副露/弃牌与座位信息 |
| **SIDE** | 状态·积分·设置·日志区 | **20%** | 100%·Ch | 积分与状态、开关设置、出牌日志 |

```text
# 像素
Tw = floor(Cw * 0.80)
Sw = Cw - Tw                 # 吸收余数，保证贴齐
Tx, Ty = 0, 0                # 客户区左上
Sx, Sy = Tw, 0
Th = Ch
Sh = Ch
```

**一致性**：TABLE 与 SIDE **等高满高**；无上下边栏侵占（日志等均在 SIDE 内）。

## 3. TABLE — 实时牌局显示区

矩形：`(Tx, Ty, Tw, Th) = (0, 0, Tw, Ch)`。

### 3.1 中心掷骰子区 DICE

在 TABLE **几何中心**放置 **正方形** 区域 **DICE**：

- 边长 `D` = `min(Tw, Th) * k`，默认 **`k = 0.28`**（可配置范围建议 0.22–0.34；实现阶段可微调）  
- 要求：DICE 与 TABLE **同心**（中心点相同）  
- 「与中心显示区等长等宽的方形」：即 DICE 为正方形，边长取中心可用尺度上的统一边长 `D`

```text
D = floor(min(Tw, Th) * 0.28)
Dx = Tx + (Tw - D) // 2
Dy = Ty + (Th - D) // 2
DICE = (Dx, Dy, D, D)
中心 C = (Tx + Tw/2, Ty + Th/2)
```

**内容（类型）**：

| 元素 | 说明 |
|------|------|
| 骰子动画/结果 | 开局掷骰定庄等 |
| 可选 | 牌山剩余概要、当前巡目（不挤占四角玩家区主信息） |

### 3.2 四角连线分区（四玩家扇区）

将 **DICE 的四个角** 与 **TABLE 的四个角** 一一对应连线，TABLE 内（DICE 外侧）划分为 **4 个玩家区**：

```text
TABLE 四角：
  TL = (Tx, Ty)
  TR = (Tx+Tw, Ty)
  BR = (Tx+Tw, Ty+Th)
  BL = (Tx, Ty+Th)

DICE 四角：
  dTL = (Dx, Dy)
  dTR = (Dx+D, Dy)
  dBR = (Dx+D, Dy+D)
  dBL = (Dx, Dy+D)

连线（逻辑分割）：
  TL—dTL, TR—dTR, BR—dBR, BL—dBL
```

四条连线 + DICE 外边界，将 TABLE \ DICE 分为四个梯形（或四边形）区域：

| 玩家区 ID | 方位 | 几何描述（TABLE 内、DICE 外） | 逻辑座位默认 |
|-----------|------|------------------------------|--------------|
| **P_SOUTH** | **下**（玩家1） | 底边 BL–BR，顶边 dBL–dBR | 玩家1 / 焦点人类默认 |
| **P_EAST** | **右**（玩家2） | 右边 TR–BR，左边 dTR–dBR | 玩家2 |
| **P_NORTH** | **上**（玩家3） | 顶边 TL–TR，底边 dTL–dTR | 玩家3 |
| **P_WEST** | **左**（玩家4） | 左边 TL–BL，右边 dTL–dBL | 玩家4 |

```text
        ┌──────── P_NORTH（上·玩家3）────────┐
        │         dTL────dTR                 │
┌───────┤          │ DICE │                  ├───────┐
│P_WEST │         dBL────dBR                 │P_EAST │
│玩家4  │                                    │玩家2  │
│ 左    └────────────────────────────────────┘  右   │
        │         P_SOUTH（下·玩家1）          │
        └────────────────────────────────────┘
```

**方位约定（本设计）**：

| 称谓 | 方位 | 说明 |
|------|------|------|
| 玩家1 | **下** | 主视角下方；与 UI 布局规范中「人类1 右下座位窗」无强制同一 seat 索引，映射见 §3.4 |
| 玩家2 | **右** | |
| 玩家3 | **上** | |
| 玩家4 | **左** | |

### 3.3 每个玩家区条带（从里到外）

沿 **桌心（DICE）→ 桌边（TABLE 外缘）** 方向，每个 `P_*` 区固定为 **三层条带**：

```text
        桌心 DICE
            │
            ▼  里
    ┌───────────────┐
    │  ZONE_DISC    │  弃牌区  ← 剩余全部厚度
    ├───────────────┤
    │  ZONE_MELD    │  副露区  ← 固定 2 行牌面高度
    ├───────────────┤
    │  ZONE_HAND    │  手牌区  ← 固定 1 行牌面高度
    └───────────────┘
            │  外
            ▼
        TABLE 外缘（玩家身前）
```

| 条带 ID | 名称 | 位置（从里到外） | 厚度（沿径向 / 朝桌边方向） | 内容 |
|---------|------|------------------|-----------------------------|------|
| **ZONE_DISC** | 弃牌区 | **最内**（靠 DICE） | **剩余区域**（见下式） | 本家弃牌网格，可多行 |
| **ZONE_MELD** | 副露区 | **中间** | **2 × 牌面高度** | 碰/杠组；可换行，高度预算为两行 |
| **ZONE_HAND** | 手牌区 | **最外**（靠桌边） | **1 × 牌面高度** | 手牌一行（明牌或牌背） |

#### 3.3.1 厚度算法（以扇区「外缘 → 内缘」可用跨度 `Span`）

统一牌面显示尺寸记为 `tile_w`，牌面高度 `tile_h ≈ tile_w × 1.4`（与 assets 1:1.4 一致）。  
**沿从外缘指向 DICE 的法向** 切条：

```text
# 外缘在桌边，内缘在 DICE 外侧
# 下家(P_SOUTH)：外=底，内=上（朝 DICE）→ 条带水平，厚度为竖直方向
# 上家：外=顶，内=下
# 左家：外=左，内=右；右家：外=右，内=左（条带竖直，厚度为水平方向；牌面可旋转 ±90°）

H_hand = tile_h + pad_row          # 1 行牌面高度（含行内边距）
H_meld = 2 * tile_h + pad_meld     # 2 行牌面高度
H_disc = max(H_disc_min, Span - H_hand - H_meld)

# 若 Span 不足（极端小窗）：
#   1) 优先保证 H_hand
#   2) 再压缩 H_meld（最低 1 行）
#   3) 最后压缩 H_disc（最低 1 行弃牌槽）
```

| 条带 | 默认厚度 | 说明 |
|------|----------|------|
| ZONE_HAND | **1 行** `tile_h` | 固定；下/上座为水平一行，左/右座为竖向一列（旋转后视觉一行） |
| ZONE_MELD | **2 行** `2×tile_h` | 固定预算；副露过多在此高度内换行或缩小牌宽 |
| ZONE_DISC | **Span − H_hand − H_meld** | **剩余全给弃牌**；靠桌心一侧 |

#### 3.3.2 四座条带朝向

| 玩家区 | 外缘 | 从外→里条带顺序 | 厚度轴向 |
|--------|------|-----------------|----------|
| P_SOUTH 下 | TABLE 底边 | 手牌 → 副露 → 弃牌 → DICE | 竖直向上 |
| P_NORTH 上 | TABLE 顶边 | 手牌 → 副露 → 弃牌 → DICE | 竖直向下 |
| P_EAST 右 | TABLE 右边 | 手牌 → 副露 → 弃牌 → DICE | 水平向左 |
| P_WEST 左 | TABLE 左边 | 手牌 → 副露 → 弃牌 → DICE | 水平向右 |

#### 3.3.3 座位信息与状态

| 元素 | 放置 |
|------|------|
| 座位标 / 头像 / 庄标 / 定缺 / 昵称 | **手牌区外侧**或手牌条两端，不占 1 行牌面厚度预算时可叠在 ZONE_HAND 两端 |
| 行牌/已胡等状态 | 贴座位标旁 |
| 积分小字 | 可选；权威汇总仍在 SIDE_TOP |

#### 3.3.4 布局原则（修订）

- **从里到外** = **弃牌 → 副露 → 手牌**（不可颠倒）。  
- 手牌贴 **桌边**（一行高）；副露居中（两行高）；弃牌吃掉扇区内 **剩余全部** 靠近桌心。  
- 左右座牌面可旋转 ±90° 朝向桌心；厚度仍按「一行 / 两行 / 剩余」计。  
- 统一 `tile_w`（可复用 F0007 主桌统一牌宽策略）。

### 3.4 逻辑 seat 映射

默认 4 人、焦点在 seat0 时：

| 玩家区 | 默认 seat | 备注 |
|--------|-----------|------|
| P_SOUTH 下·玩家1 | `focus_seat`（常 0） | 可配置 |
| P_EAST 右·玩家2 | `(focus+1) % 4` | |
| P_NORTH 上·玩家3 | `(focus+2) % 4` | |
| P_WEST 左·玩家4 | `(focus+3) % 4` | |

与多窗口布局（UI_DESIGN_STANDARD 座位窗 A/B/C）的 seat 编号一致；主桌为 **全局观战视角**，座位窗为 **单座操作/观战**。

### 3.5 当前打出 / 焦点牌

- 优先画在 **DICE 外缘与出牌玩家区交界** 或 DICE 内侧一圈预留带（不遮挡骰子结果）。  
- 可用高亮指向对应 `P_*` 区。

## 4. SIDE — 状态·设置·日志区（右 20%）

矩形：`(Sx, Sy, Sw, Sh) = (Tw, 0, Sw, Ch)`。

**纵向三等分职责**（高度可按内容权重微调，默认如下）：

| 子区 ID | 名称 | 高度占比（默认） | 职责 |
|---------|------|------------------|------|
| **SIDE_TOP** | 玩家状态与积分 | **35%** | 四家状态、积分、定缺、胡序等 |
| **SIDE_MID** | 设置开关 | **30%** | 功能开关与选项 |
| **SIDE_BOT** | 出牌日志 | **35%** | 行牌事件流 |

```text
H_top = floor(Ch * 0.35)
H_mid = floor(Ch * 0.30)
H_bot = Ch - H_top - H_mid

SIDE_TOP: y = 0,           h = H_top
SIDE_MID: y = H_top,       h = H_mid
SIDE_BOT: y = H_top+H_mid, h = H_bot
x 均为 Sx，宽均为 Sw
```

```text
┌──────────────────┐
│ SIDE_TOP  35%    │  玩家状态 + 积分
│                  │
├──────────────────┤
│ SIDE_MID  30%    │  设置开关
│                  │
├──────────────────┤
│ SIDE_BOT  35%    │  出牌日志
│                  │
└──────────────────┘
```

### 4.1 SIDE_TOP — 玩家状态与积分

| 元素 | 说明 |
|------|------|
| 局信息 | 局数、场风/庄、牌墙剩余（可选） |
| 四行座位摘要 | 座位号、名称、定缺、状态（行牌/已胡/…）、**当前积分** |
| 排序 | 建议按 seat 0→3 或按 P_SOUTH 起顺时针 |
| 交互 | 可选：点击一行切换主桌 `focus_seat` |

### 4.2 SIDE_MID — 设置开关区

承接并扩展 F0007 控制面板能力（具体项可迭代）：

| 类别 | 示例 |
|------|------|
| 显示 | 明牌/牌背、弃牌显隐、推理 HUD、策略 HUD |
| 对局 | 自动类选项（若主窗托管）、音效等 |
| 布局 | 侧栏收起（可选，收起后 TABLE 临时 100% 宽——实现阶段定） |

控件纵向排列，过长则 **区内滚动**，不侵入 TOP/BOT。

### 4.3 SIDE_BOT — 出牌日志

| 元素 | 说明 |
|------|------|
| 日志流 | 时间序或倒序：摸/打/碰/杠/胡/过/换三张/定缺等 |
| 格式 | `[巡] S{seat} 动作 牌面…` |
| 交互 | 自动滚到底；可选过滤「仅本家/全部」 |
| 容量 | 环形缓冲（如最近 200 条），避免无限增长 |

## 5. 层级与绘制顺序（建议）

```text
1. TABLE 背景（桌布）
2. 四分区底 tint（可选，弱化分隔）
3. 四家弃牌 → 副露 → 手牌
4. DICE 区背景与骰子
5. 当前打出焦点
6. SIDE 背景
7. SIDE_TOP / MID / BOT 内容
8. 全局弹层（结算、确认）居中于 Cw×Ch
```
