## 5. 原因解读（对应变化形态）

| 现象 | 解释 |
|------|------|
| **2→3 弃骤降** | 弃牌刚够触发「主色/配额/压力」启发式，但样本仍噪声大 → **错误硬约束** 压过均匀覆盖 |
| **3–4 弃谷底** | 中期规则（C4 份额、D6 配额、prefer）最伤 F1；lift 全曲线最低区 |
| **7 弃后稳步升** | 弃牌序列可辨；连续 C1 有效；向听/结构开始相关；主色一致率升到 58% |
| **>12 再升** | remain 变窄 + 信息足；best≈0.62，接近实用 |
| **Top1 升得比 best 更陡（中→后 +10pt）** | 后期排序略改善（#1 命中 49%），但仍有 gap |

---

## 6. 对「重点提高中后期」的含义

1. **中期（3–6 弃）**：先止血——减弱/关闭错误主色配额，避免 2→4 弃的 −5pt 断崖。目标：中期 best 从 **0.45 → ≥0.50**。  
2. **后期（7–12 弃）**：在已有上升通道上加压——斩色硬约束、连续补摸质量、排序校准。目标：后期 best **0.54 → ≥0.58**，Top1 **0.48 → ≥0.52**。  
3. **深局**：保持，作上限参考，非优先。

预期对 overall：中 +5pt ×28.6% + 后 +4pt ×42.9% ≈ **+0.031** overall best（约 0.51→0.54 量级）。
