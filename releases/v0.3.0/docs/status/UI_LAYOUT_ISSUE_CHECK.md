# 目视问题核查（布局顺序 / 比例 / 精简模式）

> 2026-07-21 · 对照设计文档 vs 程序

## 1. 操作按钮应在设置区上面

| 项 | 说明 |
|----|------|
| **设计** | `HUMAN_WINDOW_LAYOUT` §3：自上而下 INFO → STATUS → **OP_PLAY（手牌+操作条贴底）** → **OP_SETTINGS**。操作条属 PLAY，在设置**之上**。 |
| **原程序问题** | `btn_fr` 先 `pack(side=bottom)`，再 pack `settings_bar` → Tk 结果是 **设置在上、按钮贴底**，与设计相反。 |
| **定性** | **程序 bug**（设计正确） |
| **修正** | OP 用 place 分区；`play_actions_fr`（btn）在 `op_play` 底；`op_settings_fr` 在 OP 最底。 |

## 2. 窗内显示不全 & 区域比例不对

| 项 | 说明 |
|----|------|
| **设计** | OP 67%/EXT 33%；STATUS:PLAY = 25:55（flex）；EXT 30%/70%；MAIN 80%/20% |
| **原程序问题** | 大量 free `pack`，仅近似列宽；STATUS/PLAY 无固定高度；EXT 顶区高度不稳定；内容按自然高度溢出后靠滚动。 |
| **定性** | **程序未严格执行规范**（非文档错误） |
| **修正** | `compute_seat_interior` + `_apply_interior_geometry` **place** 强制比例；主窗 `main_interior` 严格 80/20。 |

## 3. 完整 / 精简模式

| 项 | 说明 |
|----|------|
| **设计** | F0014：同窗切换 full/hand；精简隐藏本家弃牌(B16)等；UI_DESIGN §7：宽 50% 左锚；用户要求「去掉内容 + 窗尺寸减小」。 |
| **原程序问题** | **未实现** view_mode 切换 UI；`to_compact` 仅有几何公式未接入座位窗。 |
| **定性** | **实现缺失**（设计已有，F0014/UI_DESIGN 在「高度是否缩小」上略不一致） |
| **本次实现** | 标题栏「完整 \| 精简」；精简：隐藏 EXT 弃牌带 + 宽×0.5 + 高×0.72；完整：恢复 `_full_geom_wh`。 |

## 验收建议

1. 人类窗：操作条在设置条**正上方**  
2. 扩展展开：右栏约 1/3；上 HUD/日志约 30%、下弃牌 70%  
3. 点「精简」：弃牌区消失、窗变小；点「完整」恢复
