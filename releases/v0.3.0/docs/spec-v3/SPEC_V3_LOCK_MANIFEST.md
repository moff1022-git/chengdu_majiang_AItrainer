## 1. 锁定语义

本清单冻结CSV所列规范文件的逐文件SHA-256。任何内容变化均视为锁定集变更，必须先更新受影响规格、执行跨文档审计、获得用户重新批准并提升锁定版本；不得原地静默改写。

锁定仅表示规范契约冻结，不表示现有代码、计划测试、运行证据、E3/E4/E5、AUDITED或发布通过。

## 2. 范围边界

纳入：两份上游锁定来源、治理/来源索引、正式单元目录与迁移、六份单元规格、开发契约、测试契约、审计验收契约和追踪矩阵。

不纳入：`01-audit-gap/`历史实现证据、`08-review/`审计报告、交接快照、Draft模板/提案以及锁定后新增的M0及运行证据。它们可继续append/update，但不得覆盖本清单中的规范定义。

`SPEC_V3_LOCK_MANIFEST.csv`和本文是锁定证明载体，不递归包含自身hash；其完整性由版本库、交付记录和清单内`lock_set_sha256`共同保护。

## 3. 验证方式

按CSV顺序读取每个`path`，计算文件字节SHA-256并与`sha256`列比较；再以`path|role|bytes|sha256`逐行、LF连接计算集合hash，应等于本页`lock_set_sha256`。

## 4. 后续阶段

锁定后的第一阶段为M0只读实现差距审计。M0不得修改本清单所列规范；若发现规范歧义，登记blocker并走版本化解锁/重新批准流程。
