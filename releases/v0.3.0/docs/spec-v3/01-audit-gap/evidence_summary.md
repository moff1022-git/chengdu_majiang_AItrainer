## 方法限制与稳健性

- 本轮是静态证据审计，不是运行时证明。
- 调用方通过生产源码中的符号调用扫描确认；动态分派、别名调用可能漏检，因此“未找到”不等于逻辑上绝对不存在。
- 测试有效性采用保守规则，可能漏掉只通过高层入口间接验证的测试，但不会仅凭测试名抬级。
- CSV 与 Markdown 来自同一 96 行内存矩阵，最终会做行数、枚举和 CSV 往返校验。
