## 拆分/合并复核

- `RULE-001`：规则裁决、参数解析和不变量执行具有不同变化轴；进入实现批次前确认是否保留门面并拆为内部组件。外部单元 ID 与契约保持不变。
- `ALGO-002`：牌型拆解、普通/七对向听、弃牌向听和等待形状应以同一门面下的独立纯函数实现。外部单元 ID 与契约保持不变。
- `ALGO-008`：随机流派生、噪声与思考时间应共享种子契约但分离算法职责。外部单元 ID 与契约保持不变。
- `SCORE-004`：花猪、查大叫、退税是同一终局事务内三类独立调整，需分别留守恒证据。外部单元 ID 与契约保持不变。
- `AUDIT-009`：工程回归与行为回归指标的数据源、阈值和执行频率不同，建议拆为两个内部检查器。外部单元 ID 与契约保持不变。

未发现需要合并的锁定单元；相邻单元共享数据结构时应复用 Task 16 契约，而非合并职责。
